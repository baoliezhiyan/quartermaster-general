# PPO 训练：第二阶段平面/地图对照

当前阶段请双击 [启动第二阶段对照.cmd](启动第二阶段对照.cmd)。它先显示五个独立步骤：核验 A1S1 第003轮原件、生成32局固定种子白色方案示范、仅用脚本标签做小规模行为克隆、从共同适应模型准备平面/地图起点、最后顺序训练两组。**双击后只执行你选中的一步，不自动串行启动整个实验。** 第五步输入每组新增轮数，建议首次输入 **2**（每组800局）；已有未完成计划使用 `train --continue-plan` 继续。

命令行预览：`启动第二阶段对照.cmd train --rounds 2 --dry-run`。其它阶段分别为 `verify`、`generate`、`adapt`、`prepare`；它们也支持 `--dry-run`，其中 `verify` 只读。生成示范与适应不是PPO更新。训练使用资源A、熵0.01、原第一阶段奖励，8环境、40完整局/更新、10更新/轮。先 S2FLAT 后 S2MAP，独立目录及恢复计划，决不在两个组之间串用权重或优化器。

结果位于 `第二阶段示范/`、`S2FLAT/`、`S2MAP/` 和 `.state/stage2/`、`.state/S2FLAT/`、`.state/S2MAP/`。每轮模型和最高概率自我对打的可导入回放放在 `第NNN轮/`；同一组固定评估种子对阵冻结的 A1S1 第003轮模型，概率抽样结果写入 `评估.json`。评估不进入PPO样本。技术细节、源件SHA256与限制见 [第二阶段说明](../docs/training/第二阶段白色方案示范与地图对照-20261003.md)。

## 历史：A1 语义适应阶段

双击 [启动PPO训练.cmd](启动PPO训练.cmd)，输入本次新增的 A1S1 轮数；建议先手动运行 1～2 轮。入口只运行 A1S1，不启动或续训 A2、B。资源模式 A、熵系数 0.01、无效行动惩罚 −0.01。每轮 10 次更新，每次更新完整 40 局，默认 8 个环境共享一份模型；轨迹使用有界磁盘缓存并在更新后清理。

A1S1 从保留的 `A1/第012轮/模型.pt` 显式迁移：原状态编码及候选编码前缀的权重复制，新增候选字段对应权重置零，优化器重新初始化。原 A1 权重、报告、回放及 `.state/A1/` 不变。A1S1 的奖励与编码版本已变化，属于独立实验。

| 位置 | 用途 |
| --- | --- |
| `A1S1/第001轮/` 等 | 每轮模型与一局确定性自我对打的可导入训练记录 |
| `.state/A1S1/` | 当前实验的检查点、逐批报告 |
| `.state/adapt-initial-A1S1.pt` | 从 A1 第 12 轮迁移后的独立初始权重及原件哈希 |
| `.state/adaptation-plan-A1S1.json` | 本次新增轮数、进度、原件哈希及恢复计划 |
| `.trajectory-temp/A1S1/` | 更新期间的有界轨迹文件 |
| `归档/A2-20261003-截至第012轮/` | A2 旧成果、续训状态与逐文件哈希清单 |

计划中断后再运行入口，输入 `C` 继续；也可传入 `--continue-plan`。有未完成计划时不能输入新轮数覆盖。只预览、不训练：

```cmd
启动PPO训练.cmd --rounds 1 --dry-run
```

旧 A1/A2 对照程序 `scripts/ppo_compare.py` 留作历史复现，双击入口不再调用它。地图网络在 `scripts/ppo_map_network.py` 单独准备，不替换当前默认网络。详见 [本阶段说明](../docs/training/A1语义适应与地图网络准备-20261003.md)。
