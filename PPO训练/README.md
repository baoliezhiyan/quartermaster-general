# PPO A1/A2 对照训练

双击 [启动PPO训练.cmd](启动PPO训练.cmd)，输入**本次每组新增轮数 N**。入口先顺序运行 A1 的 N 轮，再运行 A2 的 N 轮；不启动旧 B。两组均使用竞技场资源模式 A、已修正的重复建设编码和 -0.01 无效消耗训练惩罚。A1 熵系数 0.01，A2 熵系数 0.02。每轮 10 次更新，每次更新完整采集 40 局，默认 8 个持久环境共享一份 GPU 模型；每组本次新增 `N × 400` 局。

计划保存在 `.state/comparison-plan.json`。若中途停止，再次双击并输入 `C` 继续原计划；也可在命令行加 `--continue-plan`。未完成计划存在时不能新建另一份或偷偷增加 A1 轮数。两组共用 `.state/comparison-initial.pt` 的新随机初始化权重，但之后检查点与优化器完全独立。旧 `A/`、`B/` 及 `归档/` 保留原样，不参与新实验。

| 位置 | 内容 |
| --- | --- |
| `A1/第001轮/`、`A2/第001轮/` | 每轮 `模型.pt`、可导入的 `AI训练记录.jsonl` |
| `.state/A1/`、`.state/A2/` | 各自检查点与 `training-report.json`，含实际熵系数、奖励和比较指标 |
| `.state/comparison-plan.json` | 未完成/已完成计划、两组目标轮数和共用初始化哈希 |
| `.state/comparison-initial.pt` | 两组同一份全新随机初始权重 |
| `.trajectory-temp/A1/`、`.trajectory-temp/A2/` | 分组有界磁盘轨迹临时文件，更新后清理 |
| `归档/A-20261002-截至第004轮/` | 旧 A 实验模型、记录和原续训状态；只读留存 |

报告记录重复建设惩罚、可惩罚候选机会及选择比例、策略熵与最高动作概率、资源时间和轨迹清理；每轮另用固定局面检查苏联乌克兰、日本中国东部的动作偏好。小规模参考评估使用同一份未训练的冻结初始策略、固定两个种子，学习者分别控制两方，共四局。这个弱参考只用于同条件诊断，不作为整体棋力标准。每轮展示记录仍为模型贪心自我对打，并不进入训练样本。

只预览新计划而不生成权重或开始训练：

```cmd
启动PPO训练.cmd --rounds 1 --dry-run
```

预览未完成计划：`启动PPO训练.cmd --continue-plan --dry-run`。完成计划后再次输入 N 会在两组现有轮次上各新增 N 轮。训练前仍检查 CUDA；本机 Node/pnpm/Python 运行时由入口准备。详见 [对照实验说明](../docs/training/PPO-A1-A2-对照启动说明.md)。
