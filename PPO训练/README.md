# PPO 训练入口（A2S1）

当前唯一双击入口是 [启动A2S1训练.cmd](启动A2S1训练.cmd)。启动器使用本目录 `.runtime/` 中的 Node、pnpm 和 Python；如项目尚未安装依赖，会按锁文件安装。不会打开游戏或占用全屏桌面。

双击后输入本次**新增轮数**，直接回车默认为 2 轮。输入 `D` 仅预览 2 轮，不启动训练。若已有未完成计划，入口会改为询问：输入 `C` 继续原计划，输入 `D` 只预览；退出不会覆盖计划。每轮 10 次更新，每次完整 40 局，8 个环境共享一份策略。当前仅运行 A2S1；A1 系列已冻结，不再由启动器训练。

命令行只读检查：

```bat
"PPO训练\启动A2S1训练.cmd" show
"PPO训练\启动A2S1训练.cmd" new 2 --dry-run
"PPO训练\启动A2S1训练.cmd" continue --dry-run
```

模型和回放输出在 `A2S1/第NNN轮/`；检查点、报告、运行计划在 `.state/A2S1/`。旧 A1/A2/B/S2FLAT/S2MAP 的模型、报告、归档和恢复状态均保留，但旧的转发／训练 CMD 已移除，以免误启动冻结实验。项目根目录的游戏启动器与本训练入口无关。

课程身份、短验收和限制见 [A2S1 独立复验报告](../docs/training/A2S1-独立复验修复-20261004.md)。
