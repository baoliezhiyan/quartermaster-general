# PPO 训练入口

当前新增实验是 [启动A2S1连携课程.cmd](启动A2S1连携课程.cmd)。它使用已验收漏罚修复 v3 奖励，继承 A2S1 第20次更新的网络权重，独立初始化优化器；每次更新为28局正常开局＋12局真实准备的连携续局，仍共40局，8环境、熵0.01。双击输入本次新增轮数（建议先1），已有计划中断后选择继续。输入 `D` 或命令 `new 1 --dry-run` 只预览，不开训。模型与回放输出到 `A2S1C1/第NNN轮/`，独立检查点、起点池和计划在 `.state/A2S1C1/`。详细条件与已知限制见 [首版课程说明](../docs/training/A2S1-连携课程首版-20261004.md)及[遥测修复说明](../docs/training/A2S1C1-连携遥测修复-20261004.md)。

原 [启动A2S1训练.cmd](启动A2S1训练.cmd) 仍可查阅旧实验，但本阶段不作为默认续训入口。历史模型和报告均保留。

两个入口均使用本目录 `.runtime/` 中的 Node、pnpm 和 Python；如项目尚未安装依赖，会按锁文件安装。不会打开游戏或占用全屏桌面。

原 A2S1 训练已完成两轮，此入口保留旧实验的历史恢复能力，不作为本阶段新预算入口。A1 系列已冻结。

命令行示例（最后一条会启动正式续训）：

```bat
"PPO训练\启动A2S1训练.cmd" show
"PPO训练\启动A2S1训练.cmd" resume-original --dry-run
"PPO训练\启动A2S1训练.cmd" resume-original
```

模型和回放输出在 `A2S1/第NNN轮/`；检查点、报告、运行计划在 `.state/A2S1/`。旧 A1/A2/B/S2FLAT/S2MAP 的模型、报告、归档和恢复状态均保留，但旧的转发／训练 CMD 已移除，以免误启动冻结实验。项目根目录的游戏启动器与本训练入口无关。

从第 2 次更新开始，A2S1 使用 `chunk-shuffle-epoch-v1` 分块采样。每一遍仍覆盖全部样本一次；块和块内顺序随机，不能与原全局打乱的权重结果逐位比较。轨迹缓存上限 1.5 GiB，预取请求上限 256 MiB；256 样本逻辑批次拆为默认 64 样本的 GPU 梯度片段，显存不足时整批重算并降至 32、16。原第 1 次更新检查点与报告未改写；恢复副本保存在 `.state/A2S1/recovery-update-001-20261004/`。迁移只允许该检查点经 SHA256 与规则／网络／编码／奖励等完整校验后接续。

课程身份、短验收和限制见 [A2S1 独立复验报告](../docs/training/A2S1-独立复验修复-20261004.md)。
