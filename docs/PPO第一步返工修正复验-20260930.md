# PPO 第一步返工修正与复验（2026-09-30）

针对《PPO第一步返工独立复验报告-20260929.md》的阻塞项，训练适配层现在将引擎选择转换为结构化语义，再交给 Python 编码器。引擎原始选项 ID 仍只用于提交，不再承担模型的动作描述。

## 修正

- `BUILD_ORDER` 显式提供首个建设动作、地区、执行国家、兵种及后续建设动作。
- `ACTION/option` 从引擎合法行动方案取得目的地、执行动作与国家、兵种、回收源部队、攻守部队、重复建设和拦截标志。被回收单位仅以国家、兵种和原地区进入模型，实例 ID 不进入语义向量。
- 其他引擎选择依类型转换：行动地区和攻守单位、选项效果、额外打牌或获取卡牌、弃牌费用、强制调度、触发规则、效果顺序、空军防御决定等。`remove` 效果也带上被移除单位的事实。
- 未知的选择类型、字段、行动方案、地区、单位和卡牌均立即报错；Python 拒绝缺少结构化语义的选择候选。所列 `ChoiceRequest` 类型均有分支，自动结算的单一选项无需模型选取。
- 观察、动作及向量版本均升为 v3；检查点仍逐项校验这些版本、代码指纹、编码字典及网络维度。v2 权重不能作为 v3 的恢复起点。
