本次整理不改任何玩法，不把未接受的平衡提案写成规则。代码、卡面和文档不一致时应报Issue并核对裁定，不以“代码已这样写”为理由掩盖bug。

## 构建与限制

根目录README提供当前源码启动方法。发布打包依赖未纳入仓库的第三方运行时/工具和生成样例；不能把某台电脑上成功打包当作新克隆自动可打包。当前部分历史脚本仍含本机绝对路径，需要单独做可移植性修复；首次上传不批量改动这些脚本。
