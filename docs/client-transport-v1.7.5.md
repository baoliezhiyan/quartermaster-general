# v1.7.5 联机传输修复与验证

适用本地资源客户端和直接网页，无规则、随机数、卡表或回放 schema 改动。训练无行为影响；正式回放的 gameVersion 仍按现有严格匹配策略检查，使用对应版本查看旧文件。

问题和实现见 [本地客户端说明](local-client.md)。改动跨 src/network 和发布脚本：新增仅 GM 授权的 history-export，沿用原存档权限，下载在主机串行快照完成后进行。普通操作的幂等机制和大小限制保持原样，取消只读导出结果的缓存与广播。

验证：845 项测试（83 文件）、TypeScript 与生产构建通过；56 项本地/网页混合联机检查通过（本地资源字节一致、缓存、身份、重连、权限、锁定、压缩导出、服务离线）；后台 Edge 验证完整/部分普通浏览器下载、历史导入重建槽位、回放只读及页面版本。未进行真实外网隧道延迟复现，不能将本地检查等同公网稳定性保证。

2026-10-01 当前生成样例的 gzip level 1 测量，100 次平均：标准样例 101953 → 12015 字节（减少 88.2%，0.33ms）；序章样例 163215 → 23576 字节（减少 85.6%，0.58ms）。按 1Mbps 纯有效载荷估算分别从 0.82s → 0.10s、1.31s → 0.19s；不含隧道延迟和并发流量，亦不代表所有长局压缩率。

发布根目录移除本地资源客户端说明、对局记录与回放说明、对局记录与回放验收三个 Markdown，保留使用说明和嵌套回放接口文档。界面/网页标题/包版本均为 1.7.5。
