# 客户端 v1.8.0：多设备横屏适配

日期：2026-10-05。开发分支：`codex/client-mobile-v180`。基于 v1.7.7；设计依据见 [横屏适配方案](device-adaptation-plan.md)。

## 使用方式

手机和平板横屏直接打开房主网址，无需单独入口或安装客户端。竖屏显示旋转提示，旋转不会重新创建对局。地图工具内可选自动、桌面、紧凑布局；设置只保存在当前浏览器。

- 地图单指平移、双指缩放；轻点地区后可打开详情。可选兵模提供国家、兵种、地区列表辅助点选。
- 记录栏默认收起；底部“对局记录”打开，栏内 × 关闭。收起仍提示未读聊天，聊天草稿和已读状态保留。
- 手牌横向浏览，详情按钮显示完整效果。“整理手牌”中用箭头调整显示顺序，完成整理后恢复选牌；触摸不再触发桌面拖放排序。
- 选牌窗口可暂收再展开；暂收不等于跳过，不取消已选择内容。
- 工具栏折叠、图鉴自适应列数、低高度地图、GM表单滚动与卡牌详情均使用同一游戏界面。桌面继续使用鼠标操作。
- 全屏为可选功能；Windows 开房／加入脚本保持原用途，不在手机上执行。

## 验证结果

- TypeScript 与生产构建通过；保留现有大 JS 包体警告（约 830 KB，gzip 244 KB），本次未拆包。
- 规则、联机、回放等现有 Vitest 回归：89 个文件、919 项通过。
- 无头 Edge 手机触摸上下文：667×375、844×390、915×412、1024×768 的地图和底部操作栏可见，工具栏不换行。
- 实际 CDP touchStart / touchMove / touchEnd：双指缩放生效且不误选地区；触摸点选及地区详情通过。
- 手机默认收起记录、打开／关闭、图鉴、卡牌详情、箭头整理、旋转提示及恢复通过；地图和卡牌显示操作不发送游戏修改请求。
- 侧栏关闭后聊天未读提示、重开草稿保留通过。
- 桌面图鉴、正式历史存档导入、完整及部分下载、只读回放进入／退出、版本标题和导入权限回归通过。
- 自动化脚本：`scripts/test-mobile-browser.mjs`、`scripts/test-encyclopedia-browser.mjs`。目前沿用本机 Playwright/Edge 路径，需要在其他机器配置路径后运行。

## 未覆盖与后续边界

没有真实 Android／iOS／微信内置浏览器设备验收。系统软键盘、刘海安全区、手机下载、大量兵模及复杂连续响应在真实设备上的可用性仍需确认。自动化视口和合成触摸不等于这些实机测试。未提供手机性能提升百分比；此次是可用性适配，并非网络或引擎加速。

现有回归覆盖结算行为，但没有逐一实机操作全部卡牌询问。高密度窗口内容采用滚动，暂收仅用于可拖动的候选卡牌窗口；普通确认／响应提示仍保持显示。极小尺寸、系统字体放大和外接输入设备需要继续针对性观察。
