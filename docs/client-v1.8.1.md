# 客户端 v1.8.1

手机紧凑布局的卡牌宽度统一为 123.2px（原 154px 的 80%），高度 180px。完整卡图按比例缩小，剩余高度分配给可滚动文字。统一手牌、正式/序章牌库与弃牌、持续效果、候选窗口、国家公开卡牌、全卡图鉴及记录索引卡。

手机地图工具“标准视图”改为“居中视图”：保留当前缩放，将地图中心移到视口中心。桌面标准视图不变。删除页面内展开提示文字。

入口使用 viewport-fit=cover，展开界面铺满横屏区域，按钮避让刘海安全区，页面底色不再在侧面露出浅色条；监听地图容器自身尺寸变化重新计算地图。没有新增方向锁定或横屏拦截。

仅显示层改动，规则、随机数、卡表、网络、训练和回放 schema 均不变；游戏及标签页版本由 package.json 同步为 1.8.1。构建指纹重新生成，正式回放仍按现有同版本检查。

验收：构建、针对性回放测试及后台浏览器尺寸/交互检查。浏览器模拟不等于真实 iPhone 刘海、地址栏和工具栏行为验收，仍需实机确认。

补充：公开信息关闭按钮随窗口滚动保持可见；手机与电脑统一使用“设置”菜单，提供关闭/开启卡图显示，本浏览器记忆偏好，文本模式保留四边国家色条。手机双方分数置于顶部中央。仅显示偏好，不进入对局或回放数据。

手机底栏补充：按钮尺寸不变，下方预留至少 15px（半个 30px 按钮高度），如系统底部安全区更高则按安全区避让；空白属于浅色底栏。手机页面背景恢复原浅米色 #eeece5，地图自身背景不变。
