## 兼容与训练影响

游戏版本为 1.8.4；规则和构建指纹重新生成。正式回放依然要求相同版本及指纹，不绕过旧版本校验。记录协议未新增字段：仍使用已有 action/choose 与选择输入。资源池/真实手牌回放入口保留；真实手牌快照允许身份沿用已有审查策略，不冒充旧构建。

共享规则被训练场调用，因此候选选择从一次多选改为逐次单选，动作轨迹和决策数量会变化。旧冻结实验不要中途更新；训练端需重新固定构建。未修改 PPO、奖励、课程规则或模型。

## 验证

新增冻结控制器跨国确认/视角/设置及旧状态不变测试；两种模式军备触发正反例；强制征兵/驱逐舰运输第一次被响应消灭后再次选择同一地区。全量回归、类型检查和正式发布构建结果见交付说明。无手机实机验收，本轮未更改 UI 布局。
