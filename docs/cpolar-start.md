# cpolar 联机启动

推荐直接双击游戏目录外层的「启动联机版游戏（cpolar）.cmd」。首次会引导配置账号，之后自动启动隧道、取得 HTTPS 地址、启动游戏并打开本机地址 http://127.0.0.1:4183/，房主的卡图和游戏数据直接走本机。HTTPS 公网地址保留在窗口中，用于发给其他玩家。请保持窗口开启；Ctrl+C 结束本窗口启动的隧道和游戏。

## 首次准备

1. 在 https://dashboard.cpolar.com/ 注册账号，复制 AuthToken 认证令牌。
2. 在首次启动提示中粘贴令牌（不显示输入）。免费版地区通常用 cn，子域名留空。
3. 如使用付费固定网址，先在官网保留子域名，再填写该名称及与保留记录一致的地区代码，例如 cn / cn_vip / hk / us。固定名称本身不会自动开通付费权限。

令牌和选项保存在本机 `%LOCALAPPDATA%/QuartermasterGeneral/cpolar/`，不保存在游戏目录中。分享原游戏压缩包不会带上自己的令牌；换游戏版本无需重复配置。不要分享上述个人配置目录。

## 分步备用入口

- 1-配置账号和网址.cmd：首次设置或重新设置令牌、地区、固定名称。
- 2-启动cpolar隧道.cmd：等日志出现 `Tunnel established at https://...`，复制该网址。
- 3-启动联机游戏服务.cmd：粘贴网址启动游戏。游戏期间第2、3步的两个窗口都要保持开启。

包内 cpolar.exe 从用户提供的官方 cpolar_amd64.msi 提取，版本3.3.18。正常游戏无需安装系统服务，MSI仅作原始安装包备用。

若已安装的 cpolar 服务或另一个窗口正在使用同一账号，可能触发在线进程上限。请自行退出不用的 cpolar 客户端或停止对应服务后再试。启动器不会终止不属于自己的进程。不要同时启动两种穿透入口。

免费版网址可能每次变化；固定域名需要相应套餐和官网预留。隧道创建失败时不会假装启动成功；检查客户端错误后重试。无需把账号令牌发给开发者。
