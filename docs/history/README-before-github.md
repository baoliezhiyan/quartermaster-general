# 战场军需官电子游戏版

当前进入 v2 开发，版本 v0.23.0，已加入兵模详情、空军堆叠、36 像素兵模和全地图位置检查，说明见 `docs/v2-unit-display.md`。规则仍为 v1.2.2。默认新局为完整牌组：134 张基本牌加 245 张定稿特殊牌，共 379 张。保留第六步代表牌小牌组和基础牌调试局，供对照回归。完整牌组可进行 20 轮对局。

## 启动

Windows 双击根目录的 **启动游戏.cmd**，打开最新发布版 `http://127.0.0.1:4173/`。保留启动窗口，关闭窗口或按 Ctrl+C 停止服务。

可携带的完整 ZIP 在 `releases/`，最新路径记录在 `releases/latest.json`。完整解压后双击包内“启动游戏.cmd”，无需安装 Node.js、pnpm 或联网下载依赖。面向 Windows 10/11 x64，内置 Node.js 运行时。使用、升级、回滚与故障排查见 `docs/local-release-guide.md`（发布包内为“使用说明.txt”）。

开发版保留在 5173，改用 **启动开发版.cmd** 或 `pnpm dev`。开发版与发布版存档按浏览器地址分开，请从开发版导出 v1.2.2 JSON，再在发布版导入。同一发布版重复启动会复用已有服务；其他程序占用 4173 时明确报错，不擅自切换端口。

输入随机种子并点击「创建新游戏」，地图放置 8 支陆军。在地图左下手牌窗口，为六个国家分别选 7 张保留并确认；全部完成后进入德国第一回合。按阶段按钮继续，点击手牌查看合法行动；地图上的亮绿色轮廓为合法目标，也可直接点击行动列表确认。下方六国按钮可切换视角，切换不推进回合。新建对局前可取消，创建后切换至新局；原局保留在本地存档中。

**操作后自动保存到此浏览器，刷新可继续；支持 JSON 备份与导入。** 完整牌组含全部定稿特殊牌，禁牌不进入牌池。法国和中国有独立部队，在英国和美国阶段分别结算补给与计分。弃牌阶段需明确选择；弃 0 张扣 1 分，空牌库摸牌不扣分。规则和试玩说明见 `docs/step-7.md`。

完整牌组及代表牌模式中，选择手牌可查看定稿文本、指定经济战目标、勾选独立效果，再确认打出。建设和战斗的合法地区在地图上标绿，结算面板逐步询问目标、发起部队、回收方案和空军拦截。状态牌持续生效；响应必须先在出牌阶段暗置；增强只在合法时点出现。回合开始窗口同时提供资源重整与合法回合开始效果；结算结束后自动进入出牌阶段，不再单独显示回合开始操作阶段。

第四步规则试验和第五步六个示例仅在基础牌调试模式提供，方便回归验收。

## 地图操作

地图无需创建对局即可查看。点击陆地、海域或地区文字，黄色表示已选地区，再次点击取消；绿色表示当前行动的合法目标，确认后执行。右键轻点同时执行左键的选择／取消选择并查看地区信息框，可用 × 或 Esc 关闭；按住右键拖动地图，不会打开详情。支持键盘 Tab 定位、Enter/空格选择、50%—200% 缩放，每档 10%。地图外填黑，拖动范围以 50% 居中时的可见范围为界，因此 50% 下固定居中。

地图直接使用用户定稿的 `public/assets/final-map.png`，原尺寸 1743×902，叠加透明 SVG 点击区域。没有新增跨地图文字说明。右侧加拿大、美国、拉丁美洲片段共用左侧地区 ID，但不设置棋子锚点；棋子只放在左侧主体。

「中心视图」恢复 100% 并定位地图中心。「边界显示」切换透明区域轮廓，默认关闭。兵模检查入口已在验收后移除。兵模直径为 36 地图像素，各地区均有三个摆放位置，小岛蒙版按容纳空间局部拓宽；同国空军覆盖其陆海军。右键详情显示各国兵种，不显示数量。

创建后显示实际部队，并按实际陆军占领计算海峡控制方；地图视角跟随当前查看国家的阵营。默认丹麦海峡归轴心国，其余四处归同盟国。新建对局入口位于顶部横幅中央，地图保持侧边留白并随窗口高度扩展。首批 v2 改动及验证记录见 `docs/v2-map-interaction.md`。

## 开发命令

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm typecheck
pnpm build
pnpm check
pnpm preview
pnpm release
```

静态构建位于 `dist/`。`pnpm release` 先执行类型检查、测试和构建，再生成带运行时、启动器、许可证、版本及校验信息的 ZIP。发布目录按时间创建，不覆盖之前的包。不能直接双击 `dist/index.html`，请用包内启动器。

## 架构边界

界面仅通过 `GameController.dispatch(command)` 发起操作，订阅稳定的只读快照。`LocalGameController` 串行处理命令，冻结快照，防止 UI 修改规则状态。`SET_VIEW` 带 `expectedRevision`，拒绝过期命令；切换视角不会改变行动国家。规则核心不引用 React、DOM、存储或网络。

创建对局的 ID 和种子由调用方提供，同样的输入得到同样的初始状态。所有状态、命令和事件均可 JSON 序列化。牌堆归属与卡牌国家分字段保存，部队国家独立建模。默认忽略他国响应固定开启。已加入 Effect、ChoiceRequest、结算帧栈和祖先触发窗口；代表牌模式的基本行动、卡牌及阶段开始均经过结算器。玩家私密投影与交互打磨按后续阶段实现。

地图逻辑集中在 `src/core/map.ts`：127 条永久边和 5 条条件海峡边分开保存，按控制陆地和阵营查询邻居；支持可撤销的增删边覆盖。SVG 只显示地形，不用形状相接或像素距离推断规则。所有地图数据冻结为只读，选区、缩放和校验占领预览均为 UI 状态。

本地控制器已接入 IndexedDB、轮/国家起点存档、当前进度恢复、JSON 导入导出、有界回退、确定性回放校验与诊断包导出；未接入联网。

## 存档与回退快速使用

在地图下沿展开「存档、读档与备份」：大存档从第 1 轮起每轮保存德国行动前的状态；小存档每国一个，轮到该国新一轮行动时替换旧槽位。均可直接读取。

「回退一步」逐步撤销已提交的操作，最多回到当前国家本次行动开始。换国后不能退回上一国，不提供重做。刷新恢复的是当前进度，包含未结束的结算及回退记录；第 0 轮起手进度也会自动保存。

保存依赖当前浏览器与地址，建议定期导出 JSON 文件；换电脑或浏览器时导入。保存失败会明确提示。场景编辑器可调整分数、兵模和牌区，应用后可回退撤销。

地图右上角提供局部全屏：只展开地图工具栏、地图操作区和阶段栏，退出按钮或 Esc 恢复页面。图例栏已移除；原兵模检查脚本与截图保留为历史验收记录。
全屏地图支持滚轮缩放，普通页面不启用。阶段栏最右侧可回退一步；不再显示自动保存时间和可回退步数。

### v0.22.0 场景编辑与对局文件

GM 的场景编辑器按国家、兵种筛选要移除的兵模；支持抽一张牌、重洗牌库，以及移到牌库顶、底或任意随机位置（包含顶、底）。牌库第一张即下一张抽到的牌。修改立即保存并可回退。

GM 工具拆分为“回放查看”和“错误诊断”。回放查看可另存当前对局 JSON，包含种子、完整起点和已接受操作，保留起手选择、暗置响应等全知信息。推进阶段和响应选择也作为恢复时序所需命令记录。GM 修正、回退及读取起点用带原因的完整局面记录保存，因此不会丢失早先操作。文件不显示在公开对局记录中，现在可在“回放查看”中导入此文件进入只读回放模式。

新建对局重新开始当前恢复记录；会清除浏览器内旧局的全部存档、回退和回放数据；用户手动另存到磁盘的备份保留。旧存档没有完整早期记录时，以已有快照为恢复起点，标记 fromCreation=false；无法补回此前未保存的动作，但可准确恢复导出时的局面。错误诊断继续提供校验和诊断包。

### v0.22.0 房间身份

房间座位有两行：六国玩家与 GM；六国观察者与通用观察者。国家玩家固定在所选国家，完成起手、结束回合、回退后都不会自动改变座位视角。GM 使用“结算与响应查看”切换国家，保留原自动切换，并在地图上方提供当前待响应国家的快捷按钮。

六国观察者查看对应国家的地图与全部资料窗口，不能出牌、确认选择、推进阶段、配置响应或回退；响应结果的关闭仅在本地隐藏。通用观察者只显示公开地图、对局记录及六国公开信息，私有资料窗口与响应结果不会加载。身份切换仍是本地功能，尚未连接多人服务器。


### v0.23.0 回放查看

在 GM 的“回放查看”中点击“导入回放”选择对局文件。进入后六国玩家座位禁用，只能使用 GM 或观察者座位；所有对局操作（含 GM 编辑、回退、阶段推进与响应开关）均禁用。GM 可在“结算与响应查看”切换视角，观察者按原可见范围查看。浏览器刷新会恢复回放模式和当前节点。

只有 GM 能看到地图下方的“详细回放记录”和其右侧“导出当前对局为存档”。详细记录包括起手保留、具体暗置卡牌、响应选择、费用、抽弃牌、兵模和分数变化、GM 修正等。点击一条记录，即显示该操作完成后的局面；单条操作内自动结算的效果合并在该条中。纯查看视角与关闭提示不列为对局操作。

要从某节点继续玩：点击该条记录 → 导出当前对局为存档 → 在“存档、读档与备份”导入这个 JSON。导入节点存档即恢复正常模式。回放期间普通存档导出禁用，读档仍可用；新建对局也会退出回放。

已移除“查看其他本地对局”。浏览器只保留当前局：创建新局、读取另一局或载入测试场景会替换旧局的本地数据；新建对局同时清除旧局的回放、检查点、撤销和诊断记录。手动导出的文件不会删除。旧浏览器窗口不能将已删除的旧局重新写回。
