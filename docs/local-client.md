# 本地资源客户端（v1.6.6）

同一压缩包可以开房，也可以加入别人的房间。完整解压后使用最外层的四个脚本：

- `启动本地版游戏.cmd`：本机游玩。
- `启动联机版游戏（cloudflared）.cmd`：通过 Cloudflare 开房。
- `启动联机版游戏（cpolar）.cmd`：通过 cpolar 开房。
- `加入联机版游戏.cmd`：粘贴房主的完整网址，回车后打开本地资源客户端。

加入客户端不需要配置隧道账号，也不需要安装 Node。请保留整个文件夹，不能只复制 CMD。保持启动窗口开启，退出时关闭窗口或按 Ctrl+C。不要把客户端地址 `http://127.0.0.1:4184/` 发给其他人；他们填写的是房主网址。

网页、卡图、地图、样式从压缩包本地读取，首次加入也不用向房主下载它们。操作、局面、提示通过本机转接服务连接房主，仍需网络。更换房主网址不会导致重新下载卡图。与直接打开房主网址的玩家可以同局游戏；直接网址加入方式完全保留。

本机和房主必须使用相同构建的文件，不能只看版本号相同。启动时及断线重连时自动核对文件指纹，不匹配时更换为房主那份压缩包，或用浏览器直接访问房主网址。旧服务尚未支持本地客户端时，同样直接网址加入。

第一次使用本地客户端可以粘贴个人返回链接（含 `#identity=...`）沿用原身份。客户端的“复制我的返回链接”产生房主网址的个人链接，可在客户端和直接网址之间使用。个人链接不要交给其他人。客户端在同一房间保留身份记录，并与其他房间隔离；同一身份同时打开时，后打开的页面接管。

默认本机客户端端口为 4184，开房服务为 4183，可在同一台电脑运行。若提示客户端端口占用，先关闭旧的加入窗口再运行。高级使用可通过 `QM_CLIENT_PORT` 修改客户端端口。

## GM 场景锁定

在场景编辑器点击“锁定场景”，所有玩家暂时不能提交出牌、选择、弃牌、回退等游戏操作，GM 可继续编辑。完成后点击“解锁场景”。锁定只影响当前在线房间，不写入存档或回放。GM 离开 GM 座位或服务器检测到其断线时自动解锁；断网检测受心跳时间影响，不保证瞬时释放。

## 缓存与压缩

浏览器直接加入时，所有静态资源都有缓存策略：带内容版本的卡图与构建生成的脚本、样式长期缓存；未带版本的地图、标志等通过 ETag 校验，未修改时返回 304；网页入口和游戏接口不缓存。不同公网域名的浏览器缓存仍可能隔离，本地客户端通过直接读取文件解决这个问题。

较大的 WebSocket 消息启用低级别压缩，4 KiB 以下消息不压缩。旧浏览器未协商压缩时自动发送未压缩消息。本地客户端只在连接房主的网络段使用压缩，本机浏览器段不重复压缩。
