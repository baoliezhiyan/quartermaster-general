战场军需官 v0.14.3 · Windows 本地发布版
规则版本：v1.2.2

一、开始游戏

1. 将整个 ZIP 解压到任意可写文件夹。请勿在压缩包内部直接运行，也不要只复制启动脚本。
2. 双击“启动游戏.cmd”。运行窗口会显示地址，默认浏览器自动打开游戏。
3. 游戏地址固定为 http://127.0.0.1:4173/ 。若浏览器没有自动打开，手动输入该地址。
4. 游玩时保留启动窗口。结束时关闭游戏页面及启动窗口，或在启动窗口按 Ctrl+C。

本包面向 Windows 10/11 x64，内置 Node.js 运行时及地图、牌组、程序，不需要安装 Node.js、pnpm 或下载依赖。推荐使用普通模式的 Edge 或 Chrome。程序仅监听本机回环地址，不连接外部游戏服务器；断网可启动和游玩。本版不提供联机。

二、基本操作

创建完整牌组对局后，依次为六国选择并保留 7 张起手牌。阶段条在地图下沿，手牌窗口在地图左下，结算窗口在右下，均可收起。绿色地区可选，黄色地区已选，再次点击取消；确认后执行。右键轻点同时选择／取消选择并查看地区详情，按住右键拖动地图（移动超过6像素按拖动处理）。缩放为50%—200%，每档10%；50%固定居中，其他档位只能在该视野对应的外边界内拖动。地图外填黑。“中心视图”恢复100%并居中；“边界显示”开关地区轮廓。最上方绿色横幅中央可新建对局。

兵模统一为 36 地图像素直径。每个地区有三个经过边界检查的摆放位置；同国空军覆盖该国的陆军／海军，空军移走后显示底层部队。右键详情列出该地区所有国家及各自兵种，不显示数量。兵模检查已验收并移除入口。极端场景超过三个国家同驻时显示额外国家数量，完整部队仍可在右键详情查看。

基本牌只显示牌名，特殊牌显示完整文字。出牌阶段不出牌扣 1 分；征兵等替代出牌效果不扣分。弃牌阶段弃 0 张也扣 1 分。资源重整只取建设陆军、建设海军、发起陆战、发起海战。

三、存档与迁移

每次已提交操作自动保存。刷新或重新启动后，在相同浏览器、相同地址下恢复。地图下沿“存档、读档与备份”提供轮起点大存档、六国起点小存档、导入/导出 JSON。“回退一步”最多回到当前国家本轮行动起点，不支持重做。

浏览器数据属于该浏览器及地址，并不放在发布文件夹内。请定期导出 JSON 备份到自己的文件夹；清理浏览器网站数据、使用隐私模式或更换浏览器可能导致找不到原局。复制发布包本身不会复制存档。

当前开发版地址为 http://127.0.0.1:5173/，与发布版 4173 的浏览器存档分开。迁移时：在开发版导出 v1.2.2 JSON，再在发布版导入。旧规则版本存档不会自动升级；只有 v1.2.2 存档可读取。本包不修改或删除原开发版及其存档。

四、升级与回滚

升级前先导出当前局 JSON，保留旧发布包。关闭旧发布版的启动窗口，将新包解压到新的文件夹，再双击新包的启动脚本。不要把新旧文件混在一起。相同浏览器、相同 4173 地址仍能看到本地存档，但只能读取规则版本兼容的对局。

回滚时关闭新版启动窗口，从保留的旧发布文件夹启动；需要时导入升级前的 JSON 备份。规则版本不同的存档不会强制兼容。release.json 记录版本、规则版本、构建时间与运行时版本；SHA256.json 记录包内文件校验值，ZIP 旁的 .sha256 文件用于核对压缩包。

五、常见情况

• 提示 Missing runtime：重新完整解压 ZIP，确认 runtime/node.exe 存在。
• 同一个版本重复双击：复用已启动的服务，打开原地址。
• 提示 Port 4173 is in use：关闭占用该端口的其他启动窗口后再启动；程序不会擅自关闭其他进程或改用其他端口。
• 页面仍是旧版：确认旧启动窗口已经关闭，再启动所需版本并刷新页面。
• 存档读取失败：留意页面错误提示，核对规则版本；勿通过删除浏览器数据解决，先保留 JSON 备份。
• 保存失败：页面会给出提示，可先导出 JSON，避免丢失正在进行的对局。
