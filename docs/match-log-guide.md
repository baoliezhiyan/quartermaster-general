# 对局记录与事实回放（v1.7.0）

## 保存、导出和导入

正常使用任一开房脚本即可。主机持续把每局的详细 JSONL 记录写入程序旁的 `对局记录` 文件夹；目录不随启动命令的工作目录改变。运行中的文件尚无 end，查看时请点游戏上方的“导出对局记录”，下载带 SHA256 校验和 end 的固定副本。中途导出标为“截至此处”，游戏可以继续，导出不会结束主机文件。

文件内包含所有国家的手牌、暗牌和牌序等秘密。播放器的国家视角只是显示过滤，**并不使下载文件保密**。导出沿用原产品权限。

点“导入回放”选择 `.jsonl` 文件。正式局必须与客户端游戏版本完全相同。训练资源池文件按协议、schema 和必需能力检查，不要求训练程序或基准游戏版本与客户端相同。旧命令回放文件不自动冒充新格式；缺 end、断行、哈希错误或不支持的必需能力会明确拒绝。

进入后，右侧变为“详细对局记录”，保留六国入口。点击决策默认看选择前，选择后按钮看提交后；继续前进看各个子效果。可按子效果、决策、国家回合、轮次定位、跳至节点、自动播放或暂停。“展开自动步骤”控制列表是否折叠自动结算。历史问题只供查看，不需要作答。

所有面板取同一快照。全知、六国和公共视角可以切换；牌序不明确时不显示为真实顺序。卡图只使用本地可识别资源，缺图显示文件中的文字卡。资源池模式显示资源池、本周期可用、未开放、弃置/消耗，不伪装成正常手牌。退出回放恢复原界面，回放导航不向房间提交游戏操作。

## 回退、存档与恢复

回退删除目标之后的全部记录，增加 recordingRevision，不保留废弃分支。读入能与当前保留记录精确匹配的存档同样截断；外部存档另建 snapshot 起点，旧记录保留并封口。GM 修改和国家操作者变化记录为 control。

普通存档下载只带续玩数据，不附完整回放历史。主机内部保存和“恢复对局”仍保留完整记录；存档文件与回放文件分别导出。启动服务后使用原有“恢复对局”继续主机记录。

主机采用串行提交、会话日志和 JSONL 物化文件。发布新状态前须完成保存；写入失败会显示错误并停止继续写入，重启后用会话日志修复物化文件。请不要手工编辑活跃文件或 `.active-recording.json`。已下载副本不因后来回退改变。

## 公共接口（给训练端）

协议为 `quartermaster-match-log / formatVersion=2`，state/decision/event schema 均为1。共享契约在 `回放接口/contract.ts`，规范在 `回放接口/spec-v1.1.md`。类型文件不是运行时校验器。

命令行校验（从发布目录运行）：

```
runtime\node.exe scripts\validate-match-log.mjs 回放文件.jsonl
```

可选第三个参数用于指定预期的客户端 gameVersion；通常应保持发布程序默认值。验证成功退出码0，失败为1，并打印错误位置/原因。

`dist-server/Room.mjs` 导出以下公共接口，Node 22 或更高版本可直接 import：

- `parseMatchLog(text, gameVersion)`：异步；校验原始 LF 字节前缀 SHA256、运行时字段类型、实例归属、知识、版本、能力、决策及结束统计，返回 `{header,start,frames,end}`。
- `validateRecords(records, gameVersion, requireEnd=true)`：验证已解析结构，**不代替原始字节哈希校验**。
- `validateFacts(state, header)`：验证一份状态与文件声明的一致性。
- `sealMatchLog(records, stopReason?)`：固定记录前缀并生成 end；不修改传入记录。
- `replayNode(archive, seq, before=true, perspective='omniscient')`：读取目标快照；`before` 对带 action 的节点生效，返回经过视角过滤的场景、选择、事件。
- `projectFacts(state, perspective)`：按 knowledge 生成可显示视图。

视角枚举为 `omniscient`、`public` 或契约中的六国 Seat。不要把完整 archive 或 header.seed 直接送入国家视角的通用数据面板。投影是展示数据，不是可再导出的全量 State。

## 样例与验收边界

`回放样例/client-standard.jsonl` 是客户端以真实创建和六国起手命令生成的标准局中途导出。`constructed-resource-A.jsonl` / `constructed-resource-B.jsonl` 明确是构造契约样例，测试资源开放、私密视角和消耗的显示，不是训练器真实输出，不证明训练器的课程或随机采样实现正确。

尚未完成或不提供：真实训练端 A/B 完整文件的跨端联调；旧格式缺失事实的自动迁移；匹配原生引擎的规则复算；从回放节点另开可操作对局；未知未来必需结构的自动兼容。文件解析成功、哈希通过与规则正确是不同的结论，界面不会宣称已复算规则。

完整快照记录会明显增加主机磁盘用量及大文件解析开销。请在对局结束后归档不再需要的文件；不要在程序运行中删除当前记录。
