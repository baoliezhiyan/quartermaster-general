## v1.7.1 描述补充（2026-09-30）

保持动作合并、协议和规则指纹不变。回放时派生描述：记录牌区移动的具体实例、实际成功的地图动作及目标国家/地区；不把洗牌作为主条目。异步逐组生成只保留文本与卡牌引用，不保留全局面的逐帧缓存。暗置和非公开弃牌名称仅在全知或所属国家视角展示。卡牌名称可单独点击查看，点击条目其余部分仍定位场景。
