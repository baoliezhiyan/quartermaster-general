# v1.4.0 弃牌费用与攻击责任

主动手牌费用必须足额支付；检查源卡排除、指定类型及所有费用的不同牌实例。旧的单张授权不再允许以牌库顶或扣分补足。普通强制弃牌、明确弃牌库顶、战略规划后续处理与正常弃牌阶段保持原语义。

每次实际动作声明保存 decisionSeat，来源为该动作结算帧的 owner。陆地巡航者使用该决策席位承担弃牌库顶两张；不改变卡面原来的弃牌区域。法国、中国部队不再把责任强制映射给固定国家。新响应或新卡产生的攻击由其自己的帧确定责任，换视角不改变责任。

v6 文档26.3原末段误称巡航者为弃手牌，现已订正为弃牌库顶；这是文档笔误订正，不是新增改变卡面效果的规则。

规则版本升级为1.4.0。旧规则存档与回放明确拒绝导入，请用原版继续；不在未完成的费用窗口中静默改变语义。游戏身份数据不受此规则版本检查影响。
