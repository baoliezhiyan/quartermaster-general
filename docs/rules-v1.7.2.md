# v1.7.2 结算修复与规则补全

适用：正式客户端，原版和平衡补丁均适用；序章条目仅在序章开启时适用。以本次明确裁定覆盖旧结算文档中“选回祖先不关闭更深窗口”的说法。

## 触发窗口按分支关闭

一次陆攻产生同级的闪电战（special_136）和俯冲式轰炸机（special_134）机会。闪电战建设产生合成燃料（special_130）机会。建设完成后，可以立即选择合成燃料；也可以回到原陆攻的机会选择俯冲式轰炸机，但这会关闭离开的建设子窗口。之后即使出现新的合法建设地点，也不能恢复已关闭的旧建设机会。

关闭发生在触发实际进入执行时，统一覆盖普通选择、合并触发的目标选择及费用选择；未提交的引导操作仍按原回滚行为恢复。被离开的栈帧继续完成收尾与卡牌归堆，不删除已经发生的效果。仍在当前分支的祖先窗口继续有效。防守方战后优先、建设后立即响应及计分批次机制保持原规则。

印在一张牌上的顺序效果也各有时点：先建设海军再海战，先进造船厂（special_84）须在建设的后续窗口使用或跳过；海战后不得回头使用先前建设的窗口。历史上的“成功建设”事实仍然存在，但不代表触发窗口永久开放。

## 英美调度法中空军

英国的标准空军阶段调度可以选择英国或法国空军；美国可以选择美国或中国空军。由英国/美国支付通常的一张手牌调度费用，占用该国本次标准空军行动。调度目的地依空军自身国家的补给、承载部队与位置规则确定，部队国家不变。

普通【空军力量】仍只部署本国空军或用本国空军夺取制空权，不因此获得部署法国/中国空军或用它们夺取制空权的能力。特殊增强等明确授予的效果按自身牌面执行。特殊牌中的指定国家调度不自动扩展到盟国。

## 序章牌库不足时的强制弃置

因其他国家牌效须弃置序章牌库顶时，先弃置剩余序章牌；数量不足的部分改为弃置该国正式牌库顶。正式牌库仍不足时，按正式牌库不足的现行扣分规则处理。受影响国家收到实际弃置的序章牌及正式牌通知。

主动烧序章牌库顶、逐张选择的自弃不因此无限转入正式牌库。这是既有实现的文档补齐，见 v1610/v1611 回归，非本次新增平衡规则。

## 兼容与训练影响

本次不改变存档、命令或回放文件协议版本；窗口关闭原因新增 branch-left。旧存档中尚开放的结算会在继续选择时使用新关闭规则。正式回放仍严格检查游戏版本/规则指纹，旧规则回放不能冒充本次规则重执行。

共享正式引擎的训练受触发窗口与空军候选变化影响。训练独立实现须同步评估，现有冻结实验/检查点不自动升级；本次不修改训练动作编码。构建时更新规则与构建指纹。
