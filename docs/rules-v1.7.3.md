# v1.7.3 检索、牌序与马耳他潜艇群

适用范围：原版与平衡补丁的正式客户端；序章牌仅在序章启用时适用。已接受并实现的规则修订。

## 马耳他潜艇群（special_26）

德国与意大利分别结算。只有本国位于地中海的实际海军才可作为移除选项，不能移除盟国海军、其他海域海军或不存在的海军。选项提交时重新验证；过期选项拒绝。若仅剩弃牌选项，自动弃置本国牌库顶两张并通知结果。被要求选择的国家不能用跳过逃避整个效果。相同的移除或弃牌助手（special_105）采用相同合法性与单选自动规则。

## 完整检索不改变剩余牌序

取消资源重整（命令入口与结算入口）、战略规划（special_153，两种模式）、生产构思（special_151）、先进技术迭代（special_258）、检索法国牌（special_29，平衡开启）、序章检索军备（prelude_DE-16）、自由法国基地（prelude_UK-10）、战时工业东迁（prelude_SU-18）中仅为检索而进行的洗牌。拿出的牌离开后，其余牌保持原有相对顺序；这些检索本身不消耗随机数。

意大利雄心也只取走最靠顶的符合条件状态，保留剩余牌序；无符合条件牌时也不洗牌。不更改其选牌条件。

威廉皇帝学会、公共事业振兴署、一国建成社会主义等牌库顶十张检视仍保留最后的洗牌，以及此前明确的首轮落空保底。局部检视的候选范围仍由真实牌库顶决定，但候选显示顺序按 ID 排列。

## 洗回改为单牌随机插入

卡牌结算去向为“洗回牌库”时（例如配给、百团大战、湘西会战），从当前牌库长度加一的所有插入位置中随机选一个，只插入该牌；原牌库内其他牌的相对顺序不变。非空牌库每次插入消耗一个随机数，空牌库无须随机抽样。GM 的“移到牌库中”使用同一插入原语；明确置顶/置底和 GM 重洗按钮仍各按指定行为执行。

初始化、部分检视的洗牌，以及随机抽取/随机回收候选的处理保留。不能把真正的随机抽取替换为取排序后的第一张。

## 选牌显示与真实顺序分离

选牌候选按 definitionId 自然数字序，再按实例 id 排列；重复卡也有稳定的次序。服务器生成选择请求时排序，客户端弹窗亦排序以覆盖已有选择请求。未知暗牌选项不借此公开身份；非卡牌选项保持原顺序。普通牌库浏览采用同一 ID 顺序。

仅排序显示副本，不重排实际牌库，也不更改玩家的点击选择顺序。检视顶四张、置顶/置底等操作先按真实牌序确定候选范围，玩家点击的顺序决定最终放置顺序。全知回放显示的真实牌库顺序和训练资源池记录顺序继续由回放记录决定。

## 兼容与训练影响

游戏与界面版本为 1.7.3。存档/回放协议版本不变，单选自动执行标记为可选字段。随机插入复用现有回放的随机排列结果记录与注入钩子；记录中的 shuffle 行在此表示插入后的实际排列，并不意味着执行了整副洗牌。

对训练有影响：调用共享引擎时，检索后的牌序、随机流推进及部分强制选择数量改变。独立训练实现需按冻结规则决定是否同步，不自动升级现有实验/检查点。构建更新规则指纹；正式动作回放仍要求匹配版本及规则。

## 验证

最终构建下 81 个测试文件、837 项测试通过（单项时限 20 秒，2 个 worker）。覆盖马耳他无海军/有海军/过期选项/禁止跳过、完整检索保序与 PRNG 不变、部分检视仍洗牌、意大利雄心有无候选、单牌所有插入位置、ID 显示排序与用户重排次序分离、随机插入记录导出与重放。类型检查和生产构建通过。未进行真实多人手工联机验收；没有真实训练端新样例的联调声明。
