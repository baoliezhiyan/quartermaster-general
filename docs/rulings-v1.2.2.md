# v1.2.2 规则修订（2026-09-10）

本次按用户确认修订程序、卡牌显示文字及设计文档。新规则覆盖旧步骤记录中“不出牌无罚”和“手牌数量不足一律不能支付”的表述。

- **战略规划**：从摸牌堆挑选至多 2 张牌置入手牌，弃置 1 张手牌，重洗摸牌堆；删除额外打出所获牌的效果。选牌可为 0、1、2 张，弃牌处理不能主动省略。此弃牌发生在选牌后，与发动前的弃牌费用区分。
- **出牌阶段不出牌**：直接结束出牌阶段扣行动席位 1 分，包括空手。使用【征兵】等代替本阶段出牌的效果不扣分。实际合法打出后被取消或效果失效，也不按不出牌扣分。弃牌阶段弃 0 张的扣分独立保留。
- **任意手牌费用**：发动时必须有可支付手牌，准备打出的源卡不计入。手牌足额时正常支付；不足时必须弃光可支付手牌，余下弃本席位牌库顶，再不足每张扣该席位 1 分。无手牌或仅剩准备打出的源卡时不能发动。
- **指定费用**：指定牌名或牌种必须满足；混合费用只能替代任意手牌部分，不能替代指定部分。
- **其他语义**：被迫弃手牌不足仍弃光，无额外扣分；正常摸牌不足不扣分；费用不能主动省略，且不能保留手牌而改烧牌库。

费用入口已同步至资源重整、增强触发、状态行动、额外打牌、嵌套选择和规则试验工具。费用提示给出实际应选手牌数及缺额处理；缺额日志记录手牌、牌库与扣分结果。

规则版本更新为 `1.2.2`。旧规则存档不自动迁移，读取时明确拒绝以避免按新规则重放旧命令；旧存档不被删除。刷新后可创建新对局，使用同版本的大存档、小存档和回退功能。

战略规划的文本修订记录于 `src/data/card-rule-overrides.json`，全卡导入脚本会应用该修订，避免重新导入工作区保存的旧表时覆盖新文本。用户自行修改的桌面卡牌表未改动。

验证包含正常支付、费用短缺、空牌库扣分、空手禁用、排除源卡、指定牌种、混合费用、资源重整、嵌套支付、费用结算序列化、战略规划 0／1／2 张及不出牌扣分边界。Word 文档沿用源文件格式，更新正文、回合流程和验收要求，并增加第 17.4 节修订记录；已通过本机 Word 导出 PDF，逐页检查全部 38 页。
