# 第一步验收

目标依据：开发实施文档 v1.2 第 12 节「1. 项目骨架」——建立 React 前端、规则包、本地控制器、测试和一键启动；本地打开页面并创建新游戏。

本步提供 React + TypeScript + Vite 工程、独立规则模块、控制器接口及本地实现、测试、依赖锁文件和 Windows 启动入口。

手动验收流程：

1. 双击根目录「启动游戏.cmd」，打开本地指挥室。
2. 使用默认种子 1940 创建新游戏；右侧显示对局已就绪、准备阶段与对局编号，日志出现创建记录。
3. 点击任一国家；视角、操作者和手牌区标题同步更新，日志新增切换记录。
4. 点击新建对局后取消，原对局保留；再次创建则得到新的空对局。
5. 刷新页面返回未创建状态，符合本步尚无保存功能的边界。

自动测试覆盖确定性与序列化、独立牌堆、视角切换不推进回合、不可变快照、订阅取消、串行命令、过期修订拒绝、非法种子、未知命令和替换对局。

本次验证结果：TypeScript 类型检查通过；Vitest 共 2 个测试文件、11 项测试全部通过；Vite 生产构建通过。使用 Windows PowerShell 启动脚本成功启动本地服务，并在浏览器中确认创建对局、切换至日本视角及取消新建后保留原对局编号。已检查桌面页面布局。

地图模块、完整基础状态机、牌堆规则、嵌套引擎、存档回放均未开始；不能用本步进行桌游试玩。
