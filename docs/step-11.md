# 第十一步：本地发布

已完成 Windows x64 本地发布版 v0.11.0，规则基线 v1.2.2。

## 交付

- `releases/latest.json` 指向最新完整发布目录和 ZIP（约 36 MB）。
- 包内包含静态构建、定稿地图、全部卡牌数据、Node.js v24.19.0 x64、双击启动器、使用说明、版本信息、SHA256 校验和第三方许可证。
- 项目根目录的“启动游戏.cmd”启动最新发布版；“启动开发版.cmd”保留开发模式。
- 使用、存档迁移、更新和回滚说明见 `local-release-guide.md`，也已收入 ZIP 的“使用说明.txt”。

## 运行方式

完整解压后双击包内启动脚本即可；不依赖用户机器预装 Node.js、pnpm 或 Codex，不安装依赖、不请求外部资源。程序是由本机服务承载的浏览器应用，只监听 `127.0.0.1:4173`，无需单独配置服务器，不提供联网功能。

同构建重复启动复用现有服务；其他程序或不同构建占用端口时明确报错，不自动切换端口，不结束其他进程。关闭启动窗口或 Ctrl+C 可结束服务。构建文件不使用长期缓存，升级后刷新即可加载新版。

开发版继续使用 5173，存档按浏览器及来源地址隔离；已有 v1.2.2 对局通过 JSON 导出/导入迁移。发布文件夹不存放浏览器对局数据，复制 ZIP 不等于备份存档。新构建不覆盖旧发布目录，升级前导出 JSON 并保留旧包，关闭当前版本后可从旧文件夹启动回滚。旧规则版本存档仍明确拒绝读取。

## 重建与验收

`pnpm release` 执行类型检查、全部测试、静态构建和打包。Windows x64 环境使用执行该命令的 Node.js 运行时打包；修改运行时版本时，应同步 `scripts/release/licenses/NODE-LICENSE.txt` 的对应官方许可证。打包阶段用 Windows 自带 .NET ZIP API，无需额外压缩工具。

本次验证：

- 229 项自动测试通过，类型检查与构建通过。
- 本地服务器测试覆盖 HTML、JS、图片、HEAD、缓存策略、元数据、未知文件、路径穿越、Host 和写请求限制。
- 完整 ZIP 校验后解压至独立的中文及空格路径，用包内运行时在空 PATH 下启动成功。
- 解压后所有包内文件 SHA256 匹配；经 HTTP 读取的全部静态文件与磁盘逐字节一致。
- 重复启动返回成功并复用；无关程序占用端口时返回错误且不干扰该程序。
- 项目发布启动脚本成功在 4173 启动；浏览器页面正常加载世界地图、建局表单与存档工具。
- 规则仍为 v1.2.2，本步没有修改游戏规则。

独立解压验证报告保存在 `outputs/第11步 独立解压验证/verification.json`。发布包 SHA256 文件位于 ZIP 旁，包内 `release.json` 与 `SHA256.json` 用于追踪版本和核对文件。
