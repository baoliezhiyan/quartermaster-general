# 第二步地图模块（定稿底图更新）

## 呈现与交互

直接使用用户提供的最终地图 PNG，1743×902，未经修改。生产文件为 public/assets/final-map.png，SHA-256 为 f7cb2a1abf446ef010bb5fccf43f42a6a86390a59eca4b9a6ff3adaccb2e4b70，与桌面原文件一致。地名、星标、海峡箭头来自底图，不重复绘制，也不添加跨地图文字提示。

透明 SVG 与底图使用相同坐标系，54 个显示片段绑定 51 个逻辑地区。选中和相邻状态使用半透明颜色。右侧加拿大、美国、拉丁美洲与左侧共享地区 ID，右侧不设置棋子锚点。

保留搜索、键盘选择、100%—250% 缩放、拖动、邻接详情和海峡控制权预览。「欧洲视图」将整图放大到 200% 并定位日耳曼，不修改欧洲比例。统一棋子参考直径 16 地图像素，每个主体地区一个参考锚点；当前仅演示尺寸，不代表部署部队或实现多部队排布。

「边界核对」和「兵模示意」默认关闭。小岛交互轮廓适当外扩，硫磺岛预留约 36×30 像素。海域在岛屿位置留孔。

## 描边与复核

scripts/trace_map.py 提取底图墨线围成的连通区域；scripts/build_map_geometry.py 补充被地名、星标、箭头遮挡的部分，生成 src/ui/map/traced-geometry.json。开发用依赖 opencv-python-headless、numpy、scipy 安装在被忽略的 .tools/map-trace；日常游戏运行无需 Python。

复现时先运行 trace_map.py，再运行 build_map_geometry.py。开发输出 map-work/boundary-audit.png 用于目视核对，不作为生产底图。已核对全图与欧洲放大区域，并修正中东红色箭头造成的分割。小岛和被文字遮住的部分为补充的近似交互轮廓，不宣称逐像素自动描边。可用游戏内「边界核对」继续查看。

## 规则与验证

规则仍以地图审核表为准：34 陆地、17 海域、12 补给点、8 大本营；127 条永久边、5 条条件海峡边。跨图和点接触裁决不根据轮廓推断。海峡控制权面板仅预览，不修改对局。

类型检查、31 项测试和生产构建通过。测试覆盖核心回归、地图拓扑、全部地区绑定、右侧无棋子锚点，以及欧洲和硫磺岛的棋子占位轮廓容纳检查。

浏览器确认定稿图显示正常；点击右侧拉丁美洲，两侧同步选中且邻居包含东太平洋。欧洲视图定位及 200% 缩放正常，核对开关可切换。底图与原文件哈希一致。
