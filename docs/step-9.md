# 第九步：本地六国工具

入口位于地图下沿「存档与本地工具」，六国视角条保留。

- 「六国操作与结算查看」提供六国查看者/操作者切换、当前要求选择的国家、结算帧执行进度及完整结算数据。
- 直接要求他国操作时仍使用核心指定的选择者；不因查看其他国家而推进回合，也不改变默认忽略他国可选插入响应的裁决。
- 「场景编辑器」支持各国分数、兵模位置、移回储备、增加兵模，以及现有卡牌在手牌、牌库顶、弃牌、持续生效、暗置和移出区域间移动。
- 草稿不即时修改局面。只在对局进行中、起手和当前结算/强制选择结束后应用。禁止重复兵模、错误地形、超储备和重复/丢失卡牌；不能编辑行动国、阶段或随机数状态。
- 应用草稿记录为一次可回退操作。局面修订变化后草稿重新建立，旧草稿不会覆盖新局面。

本次按要求连续实现第十步，没有停在第九步等待试玩。场景工具用于调试，并非牌面行动，刻意允许调整正常行动不能直接达到的合法结构局面。
