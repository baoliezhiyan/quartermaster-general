## 第一阶段：行动语义与惩罚

候选编码新增按顺序排列的行动上下文：行动种类、执行国家、确定目标、地区现有同国／友军／敌军、已供给部队、补给点和大本营、建设新增／重复／受敌阻挡、回收、候选是否当前合法。基本牌、事件固定效果与结算选择使用同一提取函数。原有 32 个结构化效果 token 仍完整保留；新增上下文只对前 8 个行动加细化，更多行动仍由旧 token 表达。未知后续目标保持未知；不推测随机弃牌结果。`special_150` 的 `extraPlay` 在候选特征中显式标作“补回本次出牌机会”，不作为白色方案自身收益。

| 类型 | 触发条件 | 责任与限制 |
| --- | --- | --- |
| 重复基本建设 | 明确重复、无附加效果且有可确认新增部队的基本建设替代 | 出牌者的源决策，沿用原有即时检查 |
| 事件可避免的重复目标 | 当前建设地区的合法方案全为重复，同一选择点另有新增方案 | 实际选择目标的国家／决策；同一张牌最多一次 |
| 整牌空耗 | 已完成，未见新增部队、有效攻击、直接得分等收益，且有有效基本建设替代；只判断可可靠识别的效果结构 | 源决策；固定子效果部分无效而另一固定效果有效不罚 |
| 白色方案 `special_150` | 东欧征召无效、有有效替代；后续额外牌独立追踪 | 德国原出牌决策；后续牌的收益不抵消此惩罚 |
| 同回合断补 | 本回合新部队在补给清除中被移除，未用于攻击、未使其他部队获得补给，且存在有效替代 | 原建设决策；只对无附加效果、无在场状态的简单建设进行保守判定 |

每张牌的上述惩罚共用行动级 −0.01 上限；迟到的断补结果回填源决策的训练奖励，不添加对手正奖励。跨国目标选择归实际作决定者；例如美国牌让苏联选择建设地区时，选择浪费归苏联。游戏分数、胜负、合法动作、原势函数与折扣保持原样。

当前豁免范围：无法可靠证明收益的复杂状态、响应、费用及额外出牌组合；多部队事件中的部分断补；可能实际发生但被防御／取消的攻击；未知的后续补给或隐含连锁效果。豁免是避免误罚，不表示动作有战略价值。战斗、断补和利益判定不递归模拟未来。惩罚次数下降还要连同 pass、其他空放、资源消耗与棋力评估一起看。

## 迁移与第二阶段

第一阶段网络结构保持原双塔 MLP，状态输入维度不变，候选维度增加。迁移仅复制 A1 第 12 轮相同形状的层与候选输入前缀；新增候选输入列置零，优化器从新状态开始。初始策略与 A1 基线在相同候选前缀上只允许浮点矩阵乘法舍入差异；后续可训练新字段。新实验 `A1S1` 具有独立检查点、报告、种子与目录，严格版本校验仍开启。

第二阶段的 `PpoMapNetwork` 另起 `shared-regions-neighborhood-v1` 原型：从现有状态张量抽取逐地区部队、补给、控制与静态地图特征，共享地区编码，按地图邻接做一次聚合，再按候选目标地区与多行动槽顺序汇聚；无确定单目标时使用全图汇聚。其基础网络可复制第一阶段权重，地图分支输出层置零使迁移初始策略不突变。该网络**尚未接入默认 CMD 或正式 PPO 更新入口**；先用于独立推理和参数／耗时比较，待审阅后才安排与第一阶段同预算训练。当前邻接使用静态地图与海峡候选邻接，动态海峡合法性仍由规则引擎和原观察决定。

本机单局面、22 候选、CPU 双线程、5 次预热与 30 次计时的短测：状态 14491 维、候选 15887 维；平面网络 5891842 参数，地图原型 5987980 参数，增量 96138 参数（约 0.37 MiB 的 float32 权重）。中位推理耗时分别约 2.343 ms 与 2.442 ms。这个单局面短测不是端到端训练吞吐，尚未评估 8 环境 GPU 批量与轨迹文件体积变化。

本轮只允许定向测试、单局短测与初始化检查；不启动 1～2 轮适应训练，更不启动完整长训。
