# A2S1 无效行动漏罚修复（2026-10-04）

范围仅为训练竞技场的奖励判定。正式客户端规则、游戏分数、合法动作、A 资源模式、熵系数 0.01 和惩罚幅度 −0.01 均未改动。本报告所述版本为 `complete-action-settled-benefit-v3`；历史 A2S1 训练报告和检查点仍标记为 v2，不得直接续写为同一实验。

## 判定

整牌完成结算后，结合结构化效果和实际事件判断收益。二选一分支逐支分析；当前条件不成立、无敌方目标、直接得分为零均可确认为无效。可确认的有效替代包括基本建设、真实可攻击目标以及可产生收益的事件或状态行动；仅有候选按钮不算有效替代。仍无法安全分类的结构以 `uncertain_effect_structure` 单独统计，保守豁免。

主动发动状态或响应是独立决策；选择不发动、安装状态和暗置响应不因没有即时收益受罚。已发动后的有效战斗，即使被对手防御或反制，也不算主动空耗。重复建设和空攻击要等相关子效果及连携完成后再判断，不能靠 `applied=true` 判为收益。行动账本按来源卡和决策 ID 追踪，单个行动最多扣一次，子选择与父牌不重复扣罚。

断补检查记录实际因补给清除而移除的部队 ID，包括建军与补给推进发生于同一引擎命令的情形；不再因为场上有无关状态或暗置响应而整体停用。新部队全部当回合断补消失且未有有效攻击、帮助其他部队获得补给或其他实质作用时，才在阶段结算后追责原出牌决策。部分存活、确有贡献、因敌方后续行动改变补给等复杂情形保持豁免或单独诊断。

白色方案 `special_150` 后续额外出牌仅补回本次出牌机会，不作为白色方案自身收益。额外打出的牌按独立行动检查有效替代；不能仅因属于额外出牌就普遍豁免。随机费用、支付和弃牌等成本不作为正收益。

## 版本与迁移

旧 A2S1 `latest.pt`、轮次模型、报告和回放保持原件。`scripts/ppo_a2s1_waste_migrate.py --dry-run` 检查旧检查点位于完整 40 局更新边界、课程/编码/网络/牌 ID 匹配，并列出父模型与构建哈希。人工决定启用后执行不带 `--dry-run` 的脚本，写入**独立** `PPO训练/.state/A2S1W1/initial.pt` 和迁移报告；复制模型权重，重新初始化 Adam 优化器，从新实验第 0 次更新开始采新轨迹。旧 v2 轨迹和动量不混入 v3；严格恢复校验保留。此脚本只准备起点，不启动训练。

## 已知边界

替代动作分析不做所有候选的完整模拟，也不声称覆盖全部卡牌。依赖未来随机结果、复杂间接补给或无法明确关联的连携仍可被保守豁免；这些豁免按稳定卡牌 ID 与原因进入训练统计。延迟断补罚依赖引擎发出的补给移除事实，不能仅凭终局棋盘相同作判断。对手隐藏响应身份仍不进入 PPO 观察。

## 定向验收

固定局面测试确认：英国 `special_33`、`special_35` 的两个分支均空；美国 `special_115` 条件不成立；苏联 `special_62` 无目标；德国 `special_157` 和意大利 `special_237` 直接得 0 分；英国 `special_23`、`special_31` 新部队同回合全部断补；德国 `special_137` 主动空发动，均只产生一次 −0.01。英国 `special_22` 在没有基本牌但有有效事件替代时仍受罚。断补和连携的延迟罚保留来源决策 ID；Python 奖励入口只改发起者阵营的训练奖励，不改对手奖励或游戏分数。

对照验证包括：同一法国事件有效建设不罚；直接正分不罚；没有可确认有效替代不罚；安装状态不罚；无关状态不会关闭断补检查；已有兵贵神速相关测试覆盖有效后续攻击、跳过连携与对手防御；白色方案额外出牌及提交后禁止撤回的回归继续运行。训练端结构不确定时记录原因，不以“没有罚”宣称行动有效。
