# A2S1 连携课程首版（A2S1C1）

适用范围：训练竞技场的平衡规则＋资源池 A＋局势/响应白名单。此实验不修改正式游戏玩法，不启用 B 资源屏蔽，不改变奖励公式、奖励归因或熵系数（0.01）。父权重来自已完成 20 次更新、800 局的 A2S1 模型；该父检查点使用无效行动奖励 v2，本实验通过独立 `A2S1C1` 起点显式转为已验收的 v3 奖励，并新建 Adam 优化器。旧检查点和成果不改写。

冻结身份：父 A2S1 检查点文件 SHA256 `be64583a1f5062b463dab483755b45d2d6e3c8ca41e8c46d385350daad82a462`；父/新实验起点权重 SHA256 `2d122a4c1bdbc65dfb843cbb32070ea8325a3b1298e5bc33851da12154457705`；显式迁移初始文件 SHA256 `fa1155ce420dc7789edf28f4a9fc9df9efdae13c8c4bee5a4f01f8eda76c38a3`。本工作线基线提交 `d0f78a3`；此后仅训练 Python、文档和启动入口有变动，训练 arena TypeScript 构建指纹保持下述值。

## 规则核验与模板

下表中的卡牌均以稳定 ID 匹配，准备动作只能从正常初始状态的真实合法候选中选择；其他动作由冻结父策略概率抽样。`兑现`为牌已按真实费用安装/暗置后的接管点；`准备`为最后一次关键准备动作之前的真实轨迹截点。没有把已装牌放回资源池，也没有调整部队、费用、海峡或响应规则。

U2 的登陆作战并非“只要陆攻就能建设”：牌库顶费用、邻接美国海军、守军是否清空均须由引擎再判。J2 在安装第一张响应后的更早阶段，可以合法选择暂不发动，以保留至两张同时暗置；这与已承诺牌内效果的禁止空跳过不同。苏联完整保留现有响应和防御，不实现斯大林格勒或复国专项课程。

首版对照每模板只有一种，尚未覆盖 U1 重复建设但有价值攻击、无可攻击目标、G3 两守军但缺一连携、U3 无邻接海军，以及 J2 他国守军等全部组合；这些未被宣称为已验收。训练内仍会自然出现其他局面，但不能代替固定对照。

## 起点池与PPO边界

`scripts/ppo_combo_course.py` 生成 8 模板×正/对照×兑现/准备＝32 个起点，16 条独立准备种子。生成总共尝试43次，其中27次在达到目标前自然终局（G1 2、G2 1、G3 12、U1 1、U2 6、U3 5、J1/J2 0）；没有以失败种子补造规则外状态。成功的16条轨迹各从正常开局重放到保存的完整状态。生成记录和失败尝试在压缩池内。生成用时约115秒，池大小189,017字节。池校验绑定规则构建 `3a1ad8fd30fc54ceeace54302232d13d2e83a9a64bcedcb83a11a663db4654cd`、课程/观察/动作/编码版本、v3 奖励、模式 A、冻结父模型文件及权重哈希；不匹配会拒绝使用。

每次 PPO 更新仍恰好40局自然终局：28局正常开局，12局课程续局。八模板跨更新按编号确定轮转，每个模板自身的正例/对照随出现次数交替，避免模板与单一变体永久绑定；12局中8个兑现、4个准备。任务种子唯一并用于逐局策略采样；课程另记录真实准备种子。脚本准备历史不写入 PPO 样本、回报、价值目标或 GAE，接管后所有国家由同一个冻结策略决策直到自然终局。势函数第一步使用接管观察作基线，接管前累积的分数不算成新奖励；旧准备决策产生的延迟奖励也不回写到当前样本。仍按有效决策样本等权，较长续局会提供更多梯度样本，未额外逐局等权。

目前每个模板/变体/层只有一个固定可达起点。不同更新仍按不同任务种子抽样，因此后续动作可分化，但会有记住起点的风险。扩充多种起点须另建课程版本和池，不静默换文件。

## 验收与指标边界

**遥测修订：**下述首版验收数字和指标定义属于历史记录。后续发现“地图战术结果”会把不同回合的普通动作误算成指定连携；状态/响应中文类型及首次登陆范围也有漏记。当前以 [A2S1C1 连携遥测修复验收](A2S1C1-连携遥测修复-20261004.md) 的 v5 补充裁定为准；v4 只检查第一个合法起点，且要求 J1 后续陆攻产生消灭，成功率不能与 v5 直接比较。

8个正例都由真实候选按预期选择走通连携动作；这证明路径可执行，不代表模型已经会自发选择。8个对照均是合法重放起点。现有父模型对8个正例兑现点的短采集全部自然终局，G1/G2/G3/J1/J2观察到战术结果，U1/U2/U3未在该有限抽样中兑现。一次2局、276决策的短采集及单次缩小 PPO 更新通过；轨迹临时文件关闭后删除。9局全模板短采集共748个决策，也已自然结束并清理轨迹。该短测不是正式40局批次，也不能宣称棋力提升。

报告把正常开局和课程续局分开。课程逐局记录模板、变体、层、起点轮次/准备种子、安装/发动选择、触发机会、费用、实际新增/消灭的部队、无效行动惩罚、终局胜负和分差；每次更新单列模板聚合。巴顿西欧首次新增美军的来源按当时的结算来源分为基本建设、巴顿、登陆作战或其他；来源无法从合法可见的帧确认时记 `unresolved`，不猜测。战术结果用实际单位变化判定，不把仅“发动过”当作完成。正常开局的固定种子最高概率/概率抽样记录另存；有限弱父策略自我对打结果仅作接口和行为诊断，不作强度证明。

每轮输出三个带完整准备历史、起点标记和脚本/模型界线的代表性训练回放（G2、U2、J2），另有正常开局的最高概率与概率抽样回放。完整回放记录真实从开局到终局的所有操作，准备历史在头部元数据标记，不能把课程续局伪称自然开局。

## 手动启动与迁移

双击 `PPO训练/启动A2S1连携课程.cmd`，输入新增正整数轮数；建议先1轮审阅。现有计划中断后选择继续，不能重复增加预算。预览命令：

```bat
"PPO训练\启动A2S1连携课程.cmd" show
"PPO训练\启动A2S1连携课程.cmd" new 1 --dry-run
```

新实验检查点在 `PPO训练/.state/A2S1C1/`，每轮权重与回放在 `PPO训练/A2S1C1/第NNN轮/`。已有 A2S1 模型、报告和回放保留；v3 奖励转换是明确的单向新实验起点，复制网络权重、重新初始化优化器，不混用旧轨迹或删除指纹检查。启动器只在用户运行新计划后启动40局×10次/轮训练；本交付未启动正式训练。
