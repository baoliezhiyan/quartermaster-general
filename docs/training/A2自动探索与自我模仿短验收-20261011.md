## 修复与语义边界

泰国响应发动产生的征召部队，若同一回合断供移除且没有有效贡献，训练惩罚延迟到对应补给结算，并归给**发动泰国的决策**，不归给盖响应的决定。使用部队稳定 ID、结算事件来源和父子关系关联状态、响应及嵌套效果；一个完整行为只计一次。有效攻击、改善补给、整项行为另有收益时仍保守豁免。真实泰国路径（发动、出全面侵华、断供移除）回归通过；通用追踪框架已接入，但不能据此宣称所有状态和响应组合都经过真实牌例测试。

P0 编码审计发现：`special_137` 尚未安装时，SOURCE 候选仅以稳定卡牌 ID 和 `INSTALL` 动作表达，未来触发条件、费用和子效果没有完整地作为结构字段呈现；安装后的公开状态与使用次数、后续发动窗口则另有输入。本轮未擅自更换网络或观察维度。这限制了模型从未见卡推断连携价值的能力，后续可单独做版本化编码方案和迁移。

## 探索档案与筛选

探索与 PPO 自然采样严格隔离。SQLite WAL 档案可恢复，容量限定为 1000 个覆盖格、每格 3 个代表、约 1 GiB 逻辑压缩负载；三类队列依次覆盖、延续和复核。合法准备前缀从真实 reset/step 保存；分支经真实引擎 restore/step，未来随机流成对隔离，强制探索动作绝不记为 on-policy 旧概率或 GAE。策略对照复核使用固定种子、原 C4 策略及冻结的 C3 参考策略。

本次有界探索保存 183 个根/覆盖格、84 条分支。**P3 文档上限为 3 条候选，但实际额外复核了第 4 条，属于执行越界。**前三条均未通过，合规自动示范库因此为空。第 4 条英国 `special_24`（佩塔尔二世在南斯拉夫即位）的真实来源链得到有效的巴尔干消灭效果，8 对完整复核中 7 对不劣、8 对重复该路线，阵营回报平均差约 +0.00625；这些结果仅保留为越界诊断，**不进入本轮示范库或短对照**。其审计副本 SHA256 为 `1524081040c1835892224cbf098f88881de9e56aff84193f39bd4bd2d45d7e66`，当前启动器不读取该文件。不能据此推断整体棋力提高。

辅助模仿独立于 PPO，最多 2 个 64 样本小批次，学习率 1e-5；有策略 KL 0.01、价值漂移 0.15 的哨兵检查，超限回滚模型和辅助优化器，最多两次降学习率。一次空库不会修改模型。冻结库及后续合格路线仅在实验身份、规则/编码/奖励指纹一致时可读取。正式探索对数和可接受额外耗时尚未确定，由短测报告后再裁定。

## 前后台性能

固定 15 决策、热机后 3 次重复的顺序测量，关闭/开启/关闭进程级节流退出选项：总墙钟中位数分别为 3.070 / 0.609 / 3.117 秒；其中环境约 0.835 / 0.191 / 0.850 秒，编码约 1.783 / 0.320 / 1.789 秒，推理约 0.370 / 0.070 / 0.371 秒。开启时 Python 与 Node worker 均通过 Windows 官方 `GetProcessInformation`/`SetProcessInformation` 的进程电源节流接口核对实际设置，退出后恢复，进程仍为普通优先级。这个固定负载支持本机存在进程级执行速度节流的判断；**没有实际切换用户窗口为前台、遮挡、最小化做对照**，因此不声称三个窗口状态无条件同速，也不能排除 GPU 驱动、温度或其他程序竞争。命令行的 `--background-performance` 可关闭，失败会记录并退化，不改变全局电源计划。

## 对照与使用

同预算短对照单独使用 `A2AUTOBASE` 与 `A2AUTOCAND`：同一初始权重、种子、36＋4 课程、40 局完整更新、后台性能配置；候选另计探索和辅助模仿总耗时。实际两支均完成 40 局、4,984 次有效决策；基线采集 174.87 秒、PPO 更新 47.81 秒、总墙钟 238.49 秒；候选采集 173.45 秒、PPO 更新 45.44 秒、总墙钟 238.50 秒。候选额外捕获 12 个真实根、探索 2 对分支，共 100 次引擎推进、4.68 秒；没有待复核路线，示范库空，辅助更新为 0。总墙钟只差 0.002 秒，属于单次测量噪声，不代表探索没有成本；本次短对照未观察到学习信号。机器可读结果见 `PPO训练/.state/A2自动探索试验01/short-comparison.json`，只用于实现和成本诊断。

以当前 100 步/4.68 秒的极短分支速度作粗估，若以本批 4,984 个 actor 决策近似正常环境步数，探索占总量 10% / 20% / 30% 分别约需 554 / 1,246 / 2,136 步，对应短分支约 26 / 58 / 100 秒。**此估算没有包含完整八对终局复核的慢路径**；此前 P3 完整复核约 5,891 步 / 1,031 秒，若按这个速度，上述三档约为 97 / 218 / 374 秒。actor 决策数不是所有自动结算推进数，所以这里只能作为宽区间预估，不能据此确定正式比例或每更新额外时间上限。

正式人工入口是 `PPO训练/启动自动探索续训.cmd`；菜单可只看身份、运行有界接口短测、明确输入新计划轮数与每更新探索对数、从最近完整更新恢复、或在完成计划后追加轮数。每轮 10 更新、400 局。此入口不会自动启动长期训练，现有 C4、C3 与 A2 实验成果保持不变。启动器的后台性能开关当前随启动会话设置，重新打开时恢复默认开启；若需跨会话固定关闭，必须再次在菜单中切换。

仍未验证：全部同类状态/响应真实牌例；实际窗口三态；自动路线长期迁移或稳定胜率；正式探索比例与耗时上限。不得把本短对照视为长期训练效果证明。
