## 修复核验

- `choiceCandidates` 现在向网络提供结构化 choices，建设顺序包含动作种类、目标地区、国家及后续动作。
- 征召行动方案包含目标地区及回收源部队的国家、兵种、原地区。随机实例ID仍用于提交，不替代战略语义。
- Python 会拒绝缺少语义或选项数与语义数不一致的 choice。未知语义类别/行动/地区等有失败检查，避免静默编码成零。
- 观察、动作、向量及训练器升级至 v3，检查点继续核对版本与构建。

独立重放上轮的两个实际局面：A seed=929600 step=23 的不列颠群岛建陆/北海建海，以及 A seed=929602 step=57 的中国东部/东南亚回收部队。两组向量均已不同，独立网络探针也输出不同分数。实例ID替换不改变语义的测试通过。
