## 1 适用范围与版本关系

本版完整替代《战场军需官PPO第一步实施方案-v0.2.md》作为第1步实施依据；旧版保留用于追溯。总体方向沿用《战场军需官强化学习人机初版方案-v0.1.md》。第0步结论见《训练场第0步复验报告-20260929.md》。基础竞技场通过，不代表事件适配或PPO训练已通过。

第1步目标是接入小型PPO，验证完整决策管线、学习信号及A/B资源课程，并加入本版明确的事件。目标不是一次训练达到人类水平。

采用冻结的平衡后规则，包括意大利陆军兵模5、建设海军5张、发起海战3张。下述资源池规则和少数卡牌简化只属于训练课程，不修改正式游戏卡面或正式结算。

第一版不启用序章、中立、空军力量及空军体系，不加入状态、响应、增强、经济战牌。观察与接口预留这些机制，但当前按实际缺省值编码，不能伪造已实现能力。事件名称包含“条约”不意味着它是持续状态，例如【苏德友好条约】仍按事件处理。

## 3 有限资源池与A/B课程

### 3.1 共同规则

资源总数有限。四种基本牌为建设陆军、建设海军、发起陆战、发起海战；之后按实施阶段加入上述事件。没有7张手牌上限、12选7、常规摸牌或自主弃牌选牌。资源不自动补充。

正常使用、支付和强制弃置后移入相应弃牌区，不直接永久删除。正在结算的来源牌先移出可用资源。已消耗牌不能继续使用。正式游戏的回合顺序、地图、补给、计分、pass扣分和胜负规则沿用冻结规则，不能为课程另造胜利条件。

### 3.2 A：全部剩余资源开放

所有尚未消耗的资源均可主动使用；合法性与费用仍需满足。全部可用不等于无限资源。

### 3.3 B：每国周期随机开放

非基本牌：剩余实例数为N，均匀不放回抽取K个实例，K=min(N,max(6,ceil(0.6N)))。N=0、5、6、8、10、11、20时，K分别为0、5、6、6、6、7、12。按实例抽样，不按牌名抽样。

基本牌：每类按刷新时剩余数量独立判定一次，开放后该类全部剩余实例可用。

| 剩余数量 | 开放概率 |
| --- | ---: |
| ≥4 | 100% |
| 3 | 90% |
| 2 | 70% |
| 1 | 40% |
| 0 | 0% |

开局为六国各初始化一次，视为该国第一个周期；该国第一次进入自身回合不重复抽样。之后每个本国回合开始、相关选择之前刷新。开放集合持续至本国下回合，回合外额外出牌也使用现有集合。

周期内消耗只删除相应实例的开放标记，数量跨档不重掷。observe、存档恢复、响应、额外出牌和子效果均不触发刷新。不因出现无可打牌而重抽。N不包含弃牌、在场、暗置或结算中的牌。

数量档位可能产生囤积偏好，属于课程人工分布，不宣称等同真实手牌；用A作为对照验证。

### 3.4 随机弃置与支付

“弃手牌”和“弃牌库顶”统一从该国整个剩余资源池抽样，包含未开放实例，按实例等概率不放回。开放只限制主动打出，不限制被随机弃置。

主动弃手牌费用必须完整支付，不能用牌库顶代替。指定类别费用从符合条件的资源中随机支付。混合费用不得先随机消耗唯一指定类型造成虚假失败；复杂混合费用实际加入前需定义合法组合抽样。本批已经删除百团大战/湘西会战的洗回费用，不能保留空费用入口。

强制弃置、牌库顶缺额扣分等仍按冻结规则区分，不能因为统一抽样来源而合并其不足处理。每个连续弃置均以当时剩余实例为准。正在打出的来源牌、场上牌、已在结算中的牌均不参加抽样。

抽样结果在执行前不可见。日志中的私密信息按原规则限制，训练诊断不经由观察泄露。本课程只沿用第0步明确的公开有限池信息模式；未来加入隐藏弃置等机制时，须重新审定公开资源字段，不能机械公开真实游戏的剩余牌型。

## 4 事件接入必须扩展竞技场接口

第0步只支持四基础牌、只在PLAY阶段停下的接口，不足以支持本批事件。不得仅向现有池中加入事件就声称接入完成，也不能在特殊牌课程中沿用跳过全部特殊效果扫描的trainingBasicOnly快速路径。

推进原则：自动运行确定的规则，直到下一个真正需要玩家决策的节点或自然终局。无决策的中间事件仍累计分数变化和经过回合数。只有一个强制合法选项时可以自动推进；有可选跳过则属于真实选择。

决策类型至少支持：选择来源牌、选择行动或分支、选择地区/部队、选择数量及顺序、选择受援国家、受援国额外出牌、连续重建、结束可选分支。未来响应窗口使用同一机制；本批不额外加入响应卡。

出牌选择与后续目标选择按节点进行，不枚举整条连携组合。可以保留第0步联合动作接口作为独立旧课程，但本版事件课程的动作分解须固定并版本化，A/B保持一致。巴巴罗萨等在打出时确定的目标，必须按原规则先完成承诺，再逐次结算，不能在后续看到结果后重新挑选原本应预先锁定的目标。

接口必须区分activeSeat（谁的回合）、decisionSeat（谁做本次选择）、sourceSeat（效果来源/发起者）和unitCountry（部队国籍）。按正式引擎规定的决策归属执行，不因为部队国籍切换控制者。例如武器援助的受援国出牌由受援国选择。

保留第0步episodeId/gameId/decisionId/revision校验：过期、重复、跨对局动作拒绝且不改变状态。返回双方scoreDelta、turnsAdvanced、自然终局/截断标记及胜方；nextDecision允许改变决策座位。

每个步骤保留整张来源牌与子效果关联，不能把子效果、卡牌结束或国家回合结束标成episode结束。保留真实嵌套结算顺序；模型不负责模拟引擎。

### 5.2 效果与候选表示

每张事件提供有顺序的结构化效果表示：动作类别、费用、条件、目标限制、步骤依赖、谁决策、与前一步绑定关系。出牌节点即可看见整张牌的规则结构，但不得看见未发生的随机结果。当前执行位置和已确定结果另行编码。

使用固定字段顺序、类别表、数值缩放和padding/mask，保存observationSchemaVersion、actionSchemaVersion及字典。序列长度上限须覆盖本批最大合法情况并断言，禁止静默截断后半张牌。地图拓扑可以静态编码，不必每步重复传输。

同种基本牌的完全等价副本合并为一个选择，数量保留在观察中；不要因为副本多而获得多倍采样概率。不同语义、费用或绑定上下文的动作不能错误合并。训练时保存原候选顺序和mask，更新不重新生成候选或重抽开放集合。

## 6 初始网络

一个共享网络用于六个决策座位，以国家、阵营和上下文区分输入。资源池阶段不另设留牌/费用选牌网络。

| 模块 | 初始规格 |
| --- | --- |
| 局势编码器 | 两层全连接，各256维，ReLU |
| 候选编码器 | 结构化候选（含来源完整效果信息）编码到128维，ReLU |
| 策略头 | 拼接256维局势与128维候选，经128维ReLU隐藏层输出1个logit |
| 价值头 | 局势256维，经128维ReLU隐藏层输出1个标量 |
| 候选归一化 | 仅合法候选softmax，padding严格mask |
| 记忆/图像 | 无循环网络，无卡图输入，无大语言模型 |

局势只编码一次供全部候选复用。完整效果可以由版本化规则特征查表获得；顺序编码不可用无序平均池化抹掉。准确输入维数和效果编码形状由字段清单导出，开发交付必须报告实际shape和参数量，不能只给估计。

预计约50万至150万参数，不以凑齐某个参数量为目标。首版保持上述宽度，若实际输入使规模明显超出预估，先报告原因。策略输出层采用小随机初始化（可用正交初始化gain=0.01、bias=0），合法动作概率初始接近均匀；价值末层零初始化，初始V接近0。中间层正常随机初始化，不全置零。无固定开局优先级。

logit不是游戏分数、Q值或胜率；V是本方案定义的预期剩余训练回报，也不直接标成胜率。确定性前向在相同完整输入和相同权重下输出相同分布；实际采样动作可以不同。

## 7 奖励与时间

### 7.1 阵营目标

基础奖励仅在自然终局产生：本阵营胜+1，负-1，规则真的允许平局时0。终局判定遵循冻结规则，不另行调整强弱方胜利门槛。不奖励建设次数、击杀数、囤牌或单国得分；同阵营三国共享目标，不各自竞争分数。

对每个阵营定义分差d=己方总分-敌方总分。非终局势函数：

    Phi(s) = 0.3 * clip(d / 30, -1, 1)

真正终局的Phi强制为0。初始奖励折扣gamma=1，单次状态变化奖励：

    r = terminalBaseReward + Phi(nextState) - Phi(state)

例：从持平到领先2分，塑形奖励+0.02。终局必须包含势函数归零项，不能只加胜负奖励而漏掉该项。一个回合多个自动计分变化可逐项相加，也可用端点差；不得同时计算两遍。

从固定起点出发，完整对局奖励和为胜负奖励-Phi(initialState)，不把刷过的分永久叠加到胜负目标。随机残局起点也必须用自身初始Phi检查此恒等式。不要另加未经确认的终局分差奖励。

分别记录基础奖励、势函数奖励和总奖励，使用浮点数，避免整数舍入。双方奖励对称；同一阵营目标不会因控制三国而把一次终局奖励在一条轨迹内加三次。

势函数是局部学习引导，不保证解决永远全败或探索失败。在gamma=1的完整蒙特卡洛回报中，塑形项会望远镜相消；本方案借助价值学习与lambda估计传递局部反馈，不宣称凭空增加获胜信息。

### 7.2 游戏时钟与折扣

维护单调的已结束国家回合计数T。一个国家回合结束时+1，包括自动跳过/无决策回合；同回合内出牌、选点、响应、追加行动等不增加T。六个国家回合等于一轮的时间长度。

gamma=1：第一版不折扣远期奖励。游戏有有限轮数，优化整个对局结果。若以后改gamma，必须同时更新塑形、区间奖励累计和优势公式，不得只修改PPO库默认值。

lambda按游戏时间衰减，初始每完整轮lambda_round=0.95，不按API调用或选择次数衰减。其作用是优势估计的偏差/方差折中，不是奖励目标折扣。

## 8 按国家整理轨迹与优势计算

### 8.1 轨迹归属

六国共享参数，但每局按decisionSeat分别形成决策子序列。第i条到第i+1条必须是同一国家下一次决策，不一定是该国下一回合。

二者之间可穿插己方其他国家、敌方和自动结算。Ri累计该区间内本阵营的全部奖励，不只算自己直接造成的分数；Vi+1取本国下一观察，不能接到对方价值，也不能简单给对方价值取负号替代。

用累计阵营奖励账本和累计T在本国两次决策端点作差，避免嵌套时重复累计。每个国家最后一个选择之后，直至终局的奖励都要结入最后一条；没有做过选择的国家不伪造策略样本。

### 8.2 固定公式

采样期间权重固定，用旧网络保存Vi、旧logProbability和合法候选。设DeltaTi=T(nextOwnDecision)-T(currentDecision)，则：

    beta_i = 0.95 ** (DeltaTi / 6)
    delta_i = R_i + V_old(nextOwnObservation) - V_old(observation_i)
    A_i = delta_i + beta_i * A_(i+1)
    valueTarget_i = V_old(observation_i) + A_i

按每个国家的序列从后往前计算。自然终局后V_next=0、A_next=0。DeltaT=0时beta=1，不因子选择多而增加衰减；20轮对应约0.36的后续衰减系数。整张事件的第一个子效果完成不得切断轨迹。

这是按游戏时间调整lambda的GAE变体，不可直接套用默认“每个决策步gamma=0.99、lambda=0.95”的实现。增加无奖励、无耗时的中间节点不应产生额外时间折扣；价值估计本身仍可能随信息变化而不同。

第一版优势、价值目标均使用上述lambda回报；另记录完整实际回报G_i=sum(R_j,j>=i)用于诊断，不能将其与lambda目标混用。此估计不是精确因果归因，后续队友与对手的随机表现带来方差；共同策略随训练变化也会带来非平稳性，不能声称一次胜负证明每步正确。

### 8.3 自然终局与截断

首版采集完整对局。正常达到轮数上限属于规则终局；训练步数保护、程序中断或人为停止属于截断，不判负、不设置Phi=0。

异常截断的整个对局单独记录并暂不用于本批PPO更新，不保留不完整前缀冒充完整轨迹。报告截断比例和原因；若频繁发生，停止正式训练排查，不能靠不断丢弃长局掩盖问题。后续若实现截断bootstrap，另行审定跨国家终点观察契约。

## 9 PPO优化与采样协议

策略以合法候选分布随机采样，不总选最大logit。至少两个有意义选项的决策参与策略学习；强制自动步骤不伪造一个有探索意义的选择，但奖励和时间仍推进。

    ratio_i = exp(logP_new_i - logP_old_i)
    A_norm = (A - batchMean(A)) / (batchStd(A) + 1e-8)
    L_policy = -mean(min(ratio*A_norm, clip(ratio,0.8,1.2)*A_norm))
    L_value = mean((V_new - stopGradient(valueTarget))**2)
    L_total = L_policy + 0.5*L_value - 0.01*mean(legalPolicyEntropy)

优势标准化在本批有效样本上做一次，不每个小批量重新计算；价值目标使用原始未标准化A。oldLogP、A、valueTarget停止梯度且在四轮更新期间固定。不对valueTarget重新作额外奖励缩放，不叠加未说明的value clipping。

| 参数 | 初始值 |
| --- | ---: |
| Adam学习率 | 3e-4 |
| PPO clip epsilon | 0.2 |
| 每批更新epoch | 4 |
| minibatch | 256，末批可较小 |
| 每批有效决策目标 | 约4096 |
| 价值MSE系数 | 0.5 |
| 熵系数 | 0.01 |
| 全部参数梯度范数上限 | 0.5 |
| gamma | 1 |
| lambda_round | 0.95 |
| 势函数幅度 | 0.3 |

达到采样目标后停止开启新局，收完已开始的局再更新，批量可以超过4096。采样中的本批网络版本固定，不能在仍有该版本对局运行时偷偷更新并混合旧新概率。更新结束后重新采集，不跨批无限复用旧轨迹。

首轮六国均可由同一个冻结采样版本自博弈，按本国轨迹更新共享参数。另用冻结的规则/加权合法动作对手做独立评估。若另加入历史对手池，只训练当前学习者采样，不能把冻结对手动作直接当作当前策略的on-policy样本。

环境开放、随机费用和策略采样使用分别记录的随机流；种子和状态仅用于复现/恢复，不输入网络。检查点保存网络、优化器、配置/编码字典版本、构建SHA-256、训练步数、随机流及评估版本。

上述数值为已批准的初始基线，不是永不可调的常数。任何调整单独版本化、说明原因，不能在一组A/B比较中悄悄更改。

## 10 实施顺序

1. 读取第0步验收记录，固定当前构建和规则指纹；保留既有基础竞技场回归测试。
2. 实现观察编码、网络及按国家轨迹计算。先用人工可核算小轨迹测试奖励、时间、优势、PPO概率映射，尚不大规模训练。
3. 在四基本牌A上完成采样、更新、保存恢复和小规模烟雾验证；再接B概率课程。输入schema保持一致。
4. 扩展第4节决策接口并接入58张事件及课程覆盖。逐张核对平衡效果；多动作、跨国决策、额外出牌及重建场景通过后才能启动事件训练。A/B使用完全相同白名单。
5. 做受控小规模学习与独立评估，交付报告。比较使用相同环境决策预算，同时报告已完成国家回合、完整对局与墙钟时间，避免动作分解变化让步数比较失真。

首个约4096决策的完整采样批次用于测量端到端速度、内存、数值稳定性和参数更新，不用于宣称学会游戏。后续训练预算根据实测速率与项目负责人安排确定，不在本次文档更新中启动长期任务。

A/B各自训练，并交叉在A/B中对同一套冻结对手评估，使用固定未参与训练的种子。条件允许时重复独立训练种子；只做一次试验须明确结论有限。不能根据同一网络双方自博弈的合计胜率判断变强。

## 11 必须通过的验收

### 11.1 规则与接口

- 白名单58个唯一ID、国家数量正确，钢铁条约不存在；两张洗回牌无回收和相应费用节点；武器援助无摸牌但有额外出牌。
- 正式游戏中百团大战、湘西会战、武器援助原效果不受训练覆盖影响。
- 阿登先攻击后建设；巴巴罗萨目标先承诺；百团大战与先开火后谈判的来源部队绑定不丢失；三张重建事件依次合法建设。
- 白色方案及两张斯堪的纳维亚事件的额外出牌与条件完整；武器援助、民主兵工厂等决策归属符合正式规则。
- 过期/重复/跨局动作拒绝不变状态；只读observe与恢复不重抽；特殊事件不走基础牌跳过结算的快速路径。

### 11.2 课程、观察与隐私

- 非基本N边界、基本牌0至4档统计、首回合无双重刷新、回合外援助不刷新、消耗跨档不重抽。
- 随机弃置包含未开放资源、不抽来源牌、不重复支付；主动费用不足拒绝，强制缺额规则保留。
- 修改对手开放集合，在公开事实未改变时不直接影响本国观察；诊断状态/随机流不进模型。
- 效果后半段和绑定上下文进入编码；相同地图但不同结算上下文可区分；padding不截断、候选顺序与mask保存恢复一致。

### 11.3 数值与轨迹

- 手算短轨迹验证delta、beta、A和valueTarget；DeltaT=0、1、6及跨自动跳过回合均覆盖。
- 插入无奖励且不耗时的确定步骤，不改变累计回报，不增加lambda时间衰减。
- 对手/队友插入选择后接回同国家价值；法国/中国部队不等同于新的决策座位；末次选择的终局尾款不丢失。
- 各阵营完整奖励和等于终局基础奖励减初始Phi，终局塑形归零只计一次；从残局起点也成立。
- 自然终局和异常截断区分；截断不判负、不假设终局Phi为0、不参与首版更新。
- oldLogP与历史候选一致，非法候选概率为0，等价基本牌副本不重复；无NaN/Inf。
- 正负优势对受控例子的所选动作概率产生预期方向更新，保存恢复后前向结果一致。

### 11.4 学习与性能报告

分别报告阵营胜率、终局分差、平均轮数、有效选择数量、资源消耗、事件使用、专项场景成功率和B中主选不可用时的表现。记录基础/塑形奖励、价值误差、优势分布、熵、近似KL、clip比例和梯度范数。高胜率必须注明对手、座位、样本数与种子。

性能区分纯环境、日志开启、推理和完整训练；报告决策/秒、国家回合/秒、CPU/RAM/显存。先小规模并行，不能占满用户电脑后再调。当前硬件为13代i9、RTX4060 Laptop约8GB显存、16GB内存，网络预估可容纳不等于保证快速收敛。

不要仅以减少重复建设或pass作为学习成功依据，必须考虑合法取舍与规则扣分。长期全败、价值不收敛或明显策略坍缩先报告并分析，不自动改胜利门槛或加奖励。

## 12 交付与边界

实施交付：版本化规则/白名单/覆盖配置、观察和动作schema、实际网络尺寸、PPO实现与公式对应说明、测试、训练/评估/恢复命令、检查点、速度内存统计及小规模报告。报告区分“管线运行”“学到取舍”“达到可用强度”。

本版已确定首批计算基线，开发者不再自行选择折扣单位、奖励权重、国家轨迹归属或事件简化。输入具体维数、代码模块划分属于按本规格推导的工程工作；如果现有引擎与已确认规则冲突，记录并提出，不静默改规则。

剩余按实测决定的是长期训练预算、后续课程、隐藏信息记忆网络与更复杂对手池，不阻塞本版接口、计算和小规模验证的实现。

## 13 方法参考

- PPO：Schulman等，https://arxiv.org/abs/1707.06347 。本方案使用裁剪策略目标；网络尺寸及采样配置属于项目选择。
- GAE：Schulman等，https://arxiv.org/abs/1506.02438 。本方案按同国家决策串联并按国家回合时间衰减lambda，是工程适配，需自行验证，不宣称论文直接验证本游戏。
- 势函数奖励：Ng等，https://ai.stanford.edu/~ang/papers/shaping-icml99.pdf 。本方案在gamma=1、真正终局Phi=0下保持完整回报的望远镜相消；并不保证有限训练一定收敛。
