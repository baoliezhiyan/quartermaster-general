# PPO 第一步并行采集实施补充 v0.4

日期：2026-09-30。适用于训练专用 A、B 事件课程。本文替代 v0.3 第 7 节的“约 4096 决策结束采集”条件及与之冲突的训练预算；v0.3 已验收的规则、观察/动作语义、奖励、优势计算和 PPO 超参数继续有效。正式客户端、序章及中立规则不受影响。

## 批次与并行

每个更新批次先按连续种子生成确定的 **40 个完整对局任务**。任务含 jobId、seed 和 policyVersion；种子随任务走，不随 worker 走。A、B 独立运行，不在同批混用。环境完成一局即可领取未启动的下一局；全部 40 局自然终止后，按局分别计算优势，再将所有有效决策样本统一做一次 PPO 更新。局长不同会改变样本权重，本版不做逐局等权。异常、超限及非自然终局使整个批次失败，不更新；诊断保存任务清单、已完成摘要、等待任务及在途状态快照。

训练入口为 `python scripts/ppo_train.py`，实际采集器在 `scripts/ppo_parallel.py`。只建立一个 PyTorch 模型和优化器，GPU 推理由中央进程调度。每个持久 Node 进程只持有一个训练竞技场，局结束后重置复用；首个进程构建一次竞技场 bundle，其余进程载入同一 bundle。每个请求/回复核对环境、任务、对局、决策和策略版本。策略采样采用按 seed、策略版本及实验种子分开的逐局随机流，worker 调度顺序不改变抽样序列。批内模型权重冻结。

默认 5 环境；中央推理最多合并 8 个已就绪局势，等待上限 2 毫秒，不做逐步全环境屏障。padding 的候选位由原有合法动作遮罩排除。输入编码复用静态地图特征、零向量和 one-hot 索引；训练课程中跳过不可能存在的卡牌常驻触发扫描，系统触发仍执行。正式引擎路径保持原状。补给缓存键、状态复制和通信协议暂不重写：尚未有足够证据证明这些改动带来的收益大于规则失效风险。

每次完整更新后原子替换检查点，存模型、优化器、累计局数/决策数、下一任务种子、策略版本、Python/Torch/CUDA 随机状态及严格版本/规则/源码指纹。暂不支持采集中途恢复；失败批次只能从上一个完整更新边界重开同一 40 个任务。旧 v3 检查点因训练器版本和构建指纹不同而明确拒绝。

## 评估与预算

正式首轮计划是每课程 50 次更新、共 2000 局；本轮**没有启动**。正式运行前以固定 20 个未入训练的种子评估，学习者分别控制轴心和同盟，共 40 局，对阵同一冻结规则对手；第 10、20、30、40、50 次更新后重复。评估局不进入训练样本。报告包含分阵营胜率、终局分差、局长、pass、资源消耗、动作分布、PPO 损失/熵/KL/裁剪比例/价值误差/梯度范数、采集及更新时间、CPU/RAM/GPU 峰值和异常。胜负规则、奖励、课程不根据中途胜率自动修改。

短基准命令示例（各命令只做一次 40 局更新）：

```powershell
python scripts/ppo_train.py --mode A --card-set events --workers 5 --updates 1 --seed 930930 --no-eval --checkpoint outputs/ppo-parallel/smoke.pt --report outputs/ppo-parallel/smoke.json
python scripts/ppo_train.py --mode A --card-set events --workers 5 --updates 0 --seed 930930 --no-eval --resume --checkpoint outputs/ppo-parallel/smoke.pt
```

正式首轮只有负责人确认后才运行，A/B 各自使用单独检查点与报告路径。所有任务为无界面后台程序，不启动桌面全屏测试。

## 验证边界

本轮更改 `src/core/specialCards.ts` 的训练课程分支、`src/training/ppoArena.ts` 的静态版本元数据、`scripts/ppo-arena-server.mjs` 的复用/耗时协议，以及 Python 训练器。规则语义预期不变；观察及动作 schema 仍为 v3，候选意义不变。训练器及构建指纹变化使旧检查点不兼容；正式存档与正式回放契约未更改。完整回放与 PPO 轻量统计是不同通道：当前采集默认只输出摘要和失败诊断，不把终局快照声称为 full_fidelity 回放；后续若开启选定局的完整回放，必须按 `docs/match-log-spec-v1.1.md` 和当前校验器联调。

已执行的短基准、差分测试和限制见[并行采集短基准与验收报告](PPO并行采集短基准与验收-20260930.md)。
