# v1.5.11 规则与交互修订

## 平衡补丁开启时

- 意大利历史【空军军团】：紧张度 0；所有同盟国各弃置序章牌库顶 1 张牌。
- 意大利历史【反共产国际协定】：紧张度仍为 +1；苏联弃置序章牌库顶 3 张牌，意大利获得 2 分。
- 美国历史【隔离演说】：所有轴心国各弃置序章牌库顶 2 张牌。
- 美国历史【阿姆托尔格贸易公司】替换【帕奈号事件】，紧张度 0；苏联可从自己的序章弃牌堆选择 1 张军备并暗置。苏联选择，可跳过，无候选时直接完成。
- 未开启平衡补丁时，保留原版卡牌与效果。

## 结算窗口

- 平衡版【一日之狮】使用独立的回合最开始窗口 EARLY_TURN_START，先询问，再进入通常回合开始窗口及资源重整。不能资源重整后再回头使用。
- 计分阶段先执行普通 SCORE 窗口的军备、增强、建设、征召等事项，全部结束后进入 SCORE_STATUS 窗口。
- 纯加分的留场状态在 SCORE_STATUS 重新读取当前局面并计算得分；因此【黄金广场政变】的征召能计入随后【意大利殖民帝国】的分数。
- 保留纯加分状态的批量处理及英国【保持冷静，继续前进】和【破译恩尼格玛密码】的响应窗口。
- 【替代物资】作为军备查询可复制状态时，仍读取该时点原始卡牌条件；不因状态的自动加分排到最后而丢失复制能力。

## 提示与操作权

- 提示中的内部地区标识经统一中文映射显示；大纵深作战思想的地区选项直接生成中文。
- 动作选项标出所涉及部队的国家，区分同地点的不同国家部队。
- 部队所属国家不等于操作玩家。【铁托游击队】的两项征召均由苏联玩家选择；英国选项只表示征召英国陆军，不转移操作权。
- 这些调整不改变弃牌隐私、其他玩家响应权限或战斗时点优先级。
