# v1.6.10 平衡调整与结算记录

以 v1.6.9 开启平衡补丁的规则为基础。保留未开启平衡补丁的原版卡牌。中立计数和序章被动弃牌规则为底层规则。

## 底层规则
- 美国参战所需的额外轴心补给点阈值仍为4，夏威夷占领按2个计算；夏威夷计分不变。该权重不加入游戏牌面或提示。
- 序章受到其他玩家效果要求弃牌库顶时，先弃序章牌库，不足部分弃正式牌库顶。正式牌库也不足时沿用通常缺牌扣分规则。自己主动烧序章牌库顶不受此变更影响。向被弃牌者一次性列明两类弃牌，不向其他受影响者重复通报。

## 日本
- 神风敢死队改在自己的补给阶段开始询问，移除有补给的日本空军后消灭相邻同盟陆海军。既有美国、莫斯科保护范围不变；不占用空军行动，空军菜单不再列出此项。
- 天津事变：英美各弃2张序章牌库顶，获得2分。
- 甘地主导非暴力不合作运动：紧张度+1，英国弃4张序章牌库顶，获得2分。

## 苏联
- 斯大林防线：在乌克兰征召陆军。
- T-34坦克、大纵深作战思想：军备费用若支付建设陆军，免除移除另一支苏联陆军；其他手牌仍须移除。费用实际支付后再判断，取消军备不会支付费用。
- 冬季战争最终修订：计分阶段开始时，在斯堪的纳维亚建设或征召苏联陆军，由玩家选择；不再有消灭选项。
- 长征：紧张度+1。
- 军备喀秋莎改名人海突击：陆战后，在战斗地区或其相邻地区发起陆战。常规状态喀秋莎不变。
- 坦克运输：费用为建设陆军／发起陆战共2张，允许两个相同类型。

## 意大利
- 新牌库移除德国解散维希法国；旧存档中已有此牌的定义与处理保留。
- 反共产国际协定：苏联弃3张，获得2分。
- 空军军团：紧张度+1，同盟各弃1张，获得2分。
- 意大利雄心：紧张度+1，删去牌面“没有符合条件的牌则不打出”，实际缺牌处理不变。

## 美国
- 海德公园的野餐：紧张度-1，英国可弃1张序章手牌后打出另一张，美国再进行一次序章出牌。英国不执行不影响美国；美国沿用原序章手牌操作面板，可重新烧顶，额外操作结束后才判定序章结束。
- 阿姆托尔格贸易公司改替换第二次国共合作，仍为美国历史。帕奈号事件回归，弃日本4张序章牌库顶。贸易公司保留检索未打出过的序章弃牌效果。
- 生产线调至战时状态：支付军备费用后，先摸至14张手牌，再选7张按顺序置于牌库底；不足7张时处理现有手牌。
- 菲律宾侦察兵改名西太平洋先遣队：计分阶段开始时，在菲律宾、硫磺岛或印度尼西亚征召美国陆军。
- 新事件先进技术迭代：从牌库或弃牌堆任选1张状态打出，洗混牌库。
- 新增强快速生产：计分阶段开始时，可弃牌库顶1张，打出手牌中的1张状态。
