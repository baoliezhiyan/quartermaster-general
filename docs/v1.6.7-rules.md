# v1.6.7 规则与开发约定

## 术语：部队

卡牌描述中的“部队”默认仅指陆军和海军，不包含空军。只有明确写出空军、部署空军、空军防御或制空权的规则才直接作用于空军。不得根据卡名推断对象，例如【皇家空军】保护的目标只能是英国陆军或海军。

该约定适用于目标选择、部队数量计分、相邻部队条件及补给效果。空军仍按原有规则依托同地区的有补给陆海军获得补给；不能仅凭“部队获得补给”的效果使孤立空军获得补给。消灭陆海军后的依附空军处理仍按原有规则执行。

## 序章暗置与发动

序章禁止暗置响应和军备发动，不禁止通过历史牌暗置它们。【黑龙会】从常规手牌暗置一张响应，成功后抽一张常规牌。【一国建成社会主义】分别执行原版手牌暗置或平衡版支付手牌、检视牌库十张暗置响应并另取一张的效果。禁发动检查只用于触发窗口，不应用于暗置操作。

## 公开在场计数

局势、条约和持续生效栏使用同一个公开在场集合：active 区的牌，加上从 active 暂移入 resolving 且尚未结束结算的牌，按实例 ID 去重。结算区中的手牌、增强和暗置响应不能因此算成局势。联机投影视图保留 publicSourceZone 以维持一致计数。

## 本次修复

修正黑龙会错误绑定到乌克兰建设的分支；皇家空军不再保护空军；统一修正泛称部队的消灭、计分和相邻条件，包括入侵埃塞俄比亚。侧栏不再因状态进入结算区而少计一张。
