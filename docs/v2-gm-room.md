# v0.20.0 房间座位与 GM 工具

主游玩面板下紧接七个房间座位：六国和 GM。GM 独立于当前国家视角；四个本地管理栏仅在 GM 席位显示。本版本仍是同设备本地操作，并未实现联网身份鉴权。

结算与响应查看保留六国视角切换、当前结算及作答国家，移除完整结算 JSON。场景编辑器内的测试场景默认折叠；允许其他国家响应开关位于其外，新完整对局默认开启。

编辑器改为即时修改：分数离开输入框时保存；兵模移动／移回储备／添加、卡牌移动立即保存。不再有草稿应用和重置按钮。进行中的结算会重新生成待选项，正在结算的卡牌不能直接移走。每次修改都可回退。口头改卡牌效果时可手动修改对应局面结果，不会重写卡牌规则程序。

回放校验从最近的读取、回退或编辑后的基准状态，在内存中重放接受的命令，比较最终状态。通过表示同样起点与操作得到同样结果；不改变棋局，也不表示所有牌面规则已经验证正确。诊断包供定位程序问题。
