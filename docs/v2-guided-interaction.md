# v0.16.0 地图内逐步操作

正式对局不再显示右下操作栏及其开关。地图上方浮动提示呈现当前步骤，卡牌从手牌、牌库、弃牌堆或持续生效与暗置栏中选取，地区和部队直接在地图选择。需要卡牌时自动打开相应栏位；多个来源同时可用时，对应底栏按钮同时高亮。再次点击取消选择，确认才提交。可放弃的步骤显示「跳过」，必选步骤不提供跳过。

每次触发选择一张卡；同一卡对应多个时点时，再选择具体时点。同一时点剩余可用效果继续询问。必发效果仍需完整选择顺序。等待他国时只显示等待提示，具体回答国家仍在六国操作与结算查看中显示。

独立效果改为逐项决定，后续选择可以利用前面结算后获得的信息。确认首个效果后才宣告并开放他国响应；主动全部跳过时，恢复到打出前的状态。效果条件不满足而自动失效仍算已打出；一旦确认发动，即使被响应取消，也不能靠跳过后续效果撤销。费用和必发效果不作为可任意跳过的独立效果。结算快照随存档保存，恢复继续选择；系统回退仍可使用。

战斗依次选择攻击地区、防守国家兵模、发起部队；只有一个合法部队时自动省略该步。防守方选择是否空军防御，攻击方随后选择是否拦截。防守方不使用空军时，陆海军移除后继续执行空军失去依托时的强制调度规则。

- 民主兵工厂：同时高亮陆军、海军建设地区，以首次所选地块决定建设顺序；第二项可跳过，首次跳过则撤销未发动的牌。
- 卓越规划：中央临时展示牌库顶至多四张，点击编号排序，确认后第一张放在牌库顶。普通牌库栏继续按编码排序。
- 巴巴罗萨：打出前一次确定至多三个苏联兵模及顺序；逐次作战时重新选择发起部队，不能新增或更换预定目标。

场景编辑器新增四个「地图交互」固定场景，分别检查双方空军、双来源触发与四牌排序、民主兵工厂、巴巴罗萨。旧存档已在结算中的操作按已有请求继续，新发动的牌使用逐步交互；规则版本编号保持 1.2.2。


## v1.5.4 确认交互

有选牌、目标或费用要求时，先完成有效选择再允许确认；零项选择只能通过跳过提交。单一可选付费效果直接展示费用选择，不再先选择是否付费。选定内容暂存于结算帧，实际支付和执行仍经过原有响应窗口。额外打出状态牌不再重复确认安装。神风敢死队直接选择补给中的日本空军，跳过消耗本次空军行动而不移除兵模。存档保留待选内容。


## v1.5.7 海德公园的野餐

英国明确选择先弃置一张序章手牌，再打出另一张，或跳过整个英国部分。美国部分返回原序章手牌界面，重置本次出牌及此前主动弃顶限制；不额外抽牌、不切换国家、不新增回合。可重新弃牌库顶并打出一张序章牌。紧张度阈值仅在当前玩家整个序章回合完成后检查；英国的额外出牌达到阈值也不能中断美国剩余操作。
