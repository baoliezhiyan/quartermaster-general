# v2 首批地图交互修复（v0.12.0）

移除本地指挥室横幅，新建对局入口移至全局顶部中央。地图保留左右边距，视窗延伸至屏幕底部；六国视角、阶段推进、手牌及结算窗口保留。

缩放范围为 50% 至 200%，每档 10%。中心视图恢复 100% 与地图中心，不改变地区选择。地图外侧填黑。拖动边界为 50% 居中时的可见世界范围；50% 时不能拖动。右键按下后移动超过 6 像素视为拖动，轻点则打开原地区详情。边界核对更名为边界显示，移除欧洲视图、兵模示意及海峡预览控件。

规则版本继续使用 v1.2.2，未改变规则、存档格式或存储地址。同一浏览器的 4173 本地发布入口可继续使用现有 v1.2.2 存档。
