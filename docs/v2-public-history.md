# v0.18.0 公开对局记录与国家信息

新对局界面只提供完整牌组。旧调试存档与测试场景仍保留兼容读取能力。

对局记录独立于内部调试事件：记录打牌、翻开响应、状态发动、实际地图行动与额外效果；暗置只记一张响应。普通阶段推进、跳过、费用牌名及弃牌数量不进入记录。记录随对局存档和回退一起恢复。

阶段栏右侧六国按钮打开公开信息，独立于操作视角。展示手牌／牌库／暗置数量、兵模储备、持续生效状态及可见弃牌堆；法国和中国的兵模储备随英国、美国展示。

可见弃牌堆只收录公开打出／翻开和公开弃置的状态。暗弃、费用弃牌、牌库顶弃牌不收录。卡牌回到隐藏区域后清除其可见身份，之后作为隐藏弃牌支付时不再显示。

旧存档没有公开历史标记，不从包含私密信息的旧调试日志猜测；公开历史从更新后的行动开始积累。

验证覆盖暗置与翻开、私密弃牌、状态弃置、跳过恢复、阶段过滤、存档与浏览器全屏公开信息窗口。
