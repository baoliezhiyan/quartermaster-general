# v0.17.1 响应控制与跨国行动

- 响应、增强卡右上角提供默认勾选的响应开关，按卡牌实例保存；取消会跳过该牌尚未发动的询问，重新勾选后参与后续时点。已发动的效果继续结算。开关随自动存档保存，不单独占用回退步数。
- 建设陆军、建设海军、部署／调度空军交由部队所属国家的操作席位选择；征召仍由发动者选择。法国、中国分别由英国、美国操作。
- 摩尔曼斯克运输船队修正名称；先由美国征召苏联陆军，再由苏联选择建设。伦敦上空的鹰由英国选择部署。
- 钢铁条约仅在意大利自己的回合询问。
- 弃牌库顶结算向发动者显示实际弃置卡牌和空牌库扣分，卡名可点击索引，点击“知道了”关闭。
- 移除手牌数量浮标，牌库及弃牌堆窗口收窄至三列卡牌。

验证：新增核心测试覆盖跨国征召／建设、伦敦部署、钢铁条约时机、响应开关即时生效与存档、弃牌结果。浏览器验证覆盖开关刷新保存、移除浮标与三列窗口布局。
