# v0.15.0 他国响应

完整牌组和代表牌新对局默认允许他国可选响应。旧存档保留原设置，可在「场景编辑器」勾选「允许其他国家响应」。结算期间不能更改此设置。

需要他国回答时，对局暂停，没有倒计时或自动放弃。当前视角保持不变；德国视角显示等待，切换六国视角到英国后，右下角显示英国可以发动的效果和「不响应」。等待框不显示响应国家，也不提供切换按钮；需要回答的国家仅在「六国操作与结算查看」显示。费用由响应国家选择支付，响应结束后可切回行动国继续。

场景编辑器提供四个独立测试对局：布莱切利园取消云量、反潜战术取消经济战、保持冷静取消征兵、布莱切利园无费用牌对照。每次载入都会创建新测试对局，原有对局仍可从本地存档列表进入。

同时出现多个国家的可选响应时，先询问本次结算发起国，其余按六国固定顺序逐一询问。某国放弃只结束该国在当前最深时点的可选响应，不替其他国家作答。原有必发效果与嵌套结算规则继续生效。

存档保留待回答窗口、响应国家与当前视角，恢复后继续等待。规则版本仍为 v1.2.2。
